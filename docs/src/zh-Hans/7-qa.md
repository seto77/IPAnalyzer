# Q&A（常见问题）

本页汇总了被问到最多的问题以及容易误解的要点。界面名称为简体中文界面中的显示名称，括号内为英文名称。对于此处未涵盖的问题或错误报告，请使用 [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues)。

## 安装与启动

### 只出现属性窗口，看不到主窗口

主窗口位于屏幕之外。

1. 将鼠标悬停在任务栏的 IPAnalyzer 图标上，右键单击缩略图，选择 **Move**（中文版 Windows 中为“移动”），按一次方向键，然后移动鼠标。
2. 若仍无效，请退出 IPAnalyzer，打开注册表编辑器 (regedit)，删除 `HKEY_CURRENT_USER\Software\Crystallography\IPAnalyzer`，然后重新启动 IPAnalyzer（所有设置都会恢复为默认值）。

### 更新后仍在运行旧版本 / IPAnalyzer 无法启动

请直接从[最新版本](https://github.com/seto77/IPAnalyzer/releases/latest)重新安装。若安装没有覆盖旧版本，或程序无法启动，请先在 Windows 设置中将其卸载，然后再重新安装。若新版本有问题，也可以从同一发布页面安装旧版本。

### 想在没有管理员权限的电脑或 Windows on Arm 电脑上使用

- 没有管理员权限时，请使用便携版 (`IPAnalyzer-v.<version>.zip`)，它无需安装并附带 .NET 运行时。
- 在 Windows on Arm 上，请使用 arm64 安装程序 (`IPAnalyzer-setup_arm64.msi`) 或便携版 (`IPAnalyzer-v.<version>_arm64.zip`)。

详情请参见[概述中的安装](0-overview.md#安装)。

### 载入大量帧时出错。需要多少内存？

无论原始位深是多少，IPAnalyzer 都以双精度（8 字节）保存每个像素的强度。例如，5000 幅 1554×516 像素的图像仅强度就需要约 32 GB。帧数很多的数据请在内存充足的电脑上处理，或用宏分批处理。

## 读取图像

### 无法读取我所用探测器的文件

可能尚未支持该格式。请通过 [Issues](https://github.com/seto77/IPAnalyzer/issues) 或直接联系作者，并附上实际文件（最好是带有衍射图样的文件，而不仅仅是暗图像）。只有带图样的图像才能确认强度是否正确以及图像方向是否正确。

!!! note "raw 图像的宽度和高度不正确时"
    对于没有文件头的 raw 文件，探测器型号和像素数是根据文件大小推断的。实际像素数往往与产品目录值不同，因此若识别失败，请发送该文件。

### 先载入参数文件再打开图像后，参数发生了变化

IPAnalyzer **会按图像格式分别记忆相机长度、波长和像素尺寸等参数**，并在打开图像时切换为这些值。因此，请 **在打开图像之后** 再载入参数文件 (`.prm`)。扩展名不同的格式即使内容相同，也会被分别记忆。

### 每幅图像都需要重新翻转或旋转吗？

不需要。**选项 (Option) → 翻转 (Flip) / 旋转 (Rotate)** 的设置也会按图像格式记忆，下次打开同一格式的图像时会自动应用。翻转和旋转也会影响积分和图像保存（源文件不会被修改）。

### 如何处理包含多帧的文件（`.his`、`.nxs`、多页 TIFF 等）？

载入此类文件时，会打开 **序列图像 (Sequential image)** 窗口，可从中选择要显示的帧。若要将它们一起积分，请使用 **获取图谱 (Get Profile)** 下拉菜单中的 **获取所有序列图像的图谱 (Get Profiles for all sequential images)** 或 **获取所选图像的图谱 (Get Profiles for selected images)**。详情请参见[工具](3-tools.md#序列图像-sequential-image)。

## 校准

### “查找参数 (几何法)” (Find parameter (geometrically)) 和 “查找参数 (穷举法)” (Find parameter (brute force)) 应如何区分使用？

| | 几何法 (Geometrically) | 穷举法 (Brute force) |
|---|---|---|
| 原理 | 将图像分割为扇区，求出峰位置，并根据 Debye 环的椭圆形状和中心确定中心、倾斜等 | 逐步改变参数，寻找计算峰位置与拟合峰位置最吻合的组合 |
| 适用数据 | 圆环几乎整圈可见（至少五个方向） | 只记录了部分圆环、直射斑点位于图像之外、斑点状圆环 |
| 图像 | 一幅，或在不同相机长度下拍摄的两幅 | 一幅 |
| 注意事项 | 若圆环不能整圈可见，精度会下降或精修不收敛 | 需要较好的初始值；耗时 |

步骤请参见[操作步骤](4-procedures.md)和[查找参数（暴力搜索）](6-find-parameter.md)。

### 校准应使用什么标准样品？

适合使用由细小晶粒产生平滑（而非斑点状）Debye 环、且圆环尽可能整圈可见的样品。大约五个以上的圆环是一个参考标准。只有两个完整圆环时难以精确确定，此时波长或相机长度中应有一个是已知的。对于暴力搜索校准，标准物质可从 Au / CeO₂ / LaB₆ / Al₂O₃ 中选择，或选择 **其他 (Other)** 并输入晶格常数。

### 校准不收敛 / 中心不断漂移

- 固定可信的值（产品目录中的像素尺寸、已知波长等），减少精修变量的数量。
- 先用少数几个低角度圆环粗略拟合，再加入高角度圆环。
- 一个分析失败的圆环可能扰乱整个结果。若某个圆环在环中心图中明显偏离，请将其移除。
- 若加入高角度圆环后拟合失败，请将峰限制为圆环仍整圈可见的峰，扩大拟合范围，并减少扇区数。
- 开始前请输入尽可能正确的初始值。

### 相机长度和波长是否必须固定其中之一才能确定？

使用晶格常数准确已知的标准物质时，即使只有一幅图像也能同时确定两者（根据圆环位置的比值）。但是，**仅凭一幅图像无法同时确定相机长度和像素尺寸**。请信任产品目录中的像素尺寸并将其固定。若有两幅相机长度差已知的图像（双暗盒法），则像素尺寸也可以精修。

### 没有记录到直射斑点 / 直射斑点位于图像之外

请手动输入直射斑点的位置，并取消 **获取图谱 (Get Profile)** 下拉菜单中的 **获取图谱前查找中心 (Find Center before Get Profile)**。若斑点位于图像之外，坐标为负值也没有问题。此类数据请使用暴力搜索校准。

### 由查找中心 (Find Center) 得到的中心与校准得到的中心相差几个像素

两者的确定方式不同。**查找中心 (Find Center)** 在当前中心附近用二维 pseudo-Voigt 函数拟合直射斑点。校准不使用直射斑点的强度，而是根据多个 Debye 环的椭圆中心求出中心。只要倾斜确定正确，就可以直接使用校准得到的中心。若直射斑点饱和，请用 **绘制环 (Draw ring)** 在某个 Debye 环上显示圆，然后按 **查找中心 (Find Center)**：此时会根据圆环确定中心。

### 什么是球面校正 (Spherical correction)？

这是针对弯曲成球面状的探测器的校正。请输入曲率半径的倒数 1/R (mm⁻¹)。平板探测器请输入 0。当高角度圆环不吻合时（例如大型探测器放置在离样品很近的位置）会有帮助。

### 如何换算其他软件（如 PIP）的倾斜值？

PIP 的 (β, Φ) 换算为 IPAnalyzer 的 (φ, τ) = (270° − β, Φ)。定义请参见[概述](0-overview.md#与-winpip-的关系)。

## 积分与输出

### 结果的横轴看起来不对 / 强度看起来几乎恒定

请检查属性窗口的 **积分属性 (Integral Property)** 选项卡中是否选择了 **径向积分 (Radial integration)**。在该模式下，谱线的横轴为方位角 χ。通常的 2θ–强度谱线需选择 **同心积分 (Concentric integration)** 获得。

### 不使用 PDIndexer，想将谱线保存到文件

在属性窗口的 **"获取图谱"之后 (After "Get Profile")** 选项卡中，于 **Save File** 下设置保存位置（与图像相同的文件夹 / 每次选择）和格式（PDI / CSV / TSV / GSAS）。这样每次积分时都会保存谱线。

### CSV 的第三列是什么？

是强度的计数误差，由每个步长内像素强度之和（视为计数）的平方根计算得到。第二列的强度已换算为相当于 Bragg–Brentano 几何的值，因此它并不等于第三列的平方。PDIndexer 可将其显示为误差棒。

### CSV 中的 2θ 只有两位小数。这是精度极限吗？

不是。这只是因为积分设置为例如起始值 20.00°、步长 0.01° 才看起来如此。计算以双精度进行。结果的精度由相机长度和波长等输入参数的误差决定。

### 对于序列图像，应使用平均 (Average) 还是求和 (Summation)？

两者的 S/N 比相同。**求和 (Summation)** 能给出正确的误差估计，因此推荐用于 Rietveld 精修等使用误差的分析。

### 想按方位角（按扇区）进行积分

打开 **获取图谱 (Get Profile)** 下拉菜单中的 **方位角分割分析 (Azimuthal Division Analysis)**，设置 **分割数 (Number of divisions)**，然后进行积分。会生成一条整体谱线（名称以 `-whole` 结尾）以及每个扇区各一条谱线（附加起始角度，如 `-000`、`-010`、…）。分割数过多时，发送到 PDIndexer 的数据可能会过大。

### 想要 2θ 与方位角 χ 的二维图（展开图像）

使用工具栏上的 **展开图像 (Unroll image)**。在属性窗口的 **展开图像选项 (Unrolled Image Option)** 选项卡中设置范围和步长。使用 **文件 (File) → 保存图像 (Save image)** 时，TIFF 保留计算得到的浮点值，PNG 保存屏幕上显示的内容。

### 想知道图像中某个矩形区域的强度总和或平均值

在图像上按 Ctrl + 右键拖动选择矩形。统计量会显示在底部的 **统计信息 (Statistical Information)** 选项卡中。对于序列图像，可以在各帧之间比较同一区域。

### 暗图像在高角度边缘变亮

若在属性窗口的 **波源 (Wave source)** 中打开了 **校正线偏振 (Correct linear polarization)**，该校正也会作用于并非来自 X 射线的信号（暗电流、电子噪声），使高角度一侧变亮。对暗图像请将其关闭。

### 想扣除暗图像（背景）

在属性窗口的 **背景选项 (Background Option)** 选项卡中，将当前图像登记为背景并设置系数。此后它会自动从相同尺寸的图像中扣除。详情请参见[属性窗口](2-property-windows.md)。

## 批处理与宏

### 想一次积分大量文件

**获取所有序列图像的图谱 (Get Profiles for all sequential images)** 用于一个文件中包含的多帧。若要处理多个文件，请使用[宏](5-macro/index.md)。[示例](5-macro/2-examples.md)中有一个依次积分所选文件并保存 CSV 文件的宏。运行之前，请先打开一幅图像并载入参数文件（参见[参数的记忆](#先载入参数文件再打开图像后参数发生了变化)）。

### 想从菜单调用常用的宏

在宏编辑器中为宏命名并添加，之后即可从主窗口的 **宏 (Macro)** 菜单中调用。

### 想在测量过程中对到达的图像即时进行积分

用[自动流程 (Auto procedure)](3-tools.md#自动流程-auto-procedure) 监视文件夹。仍在写入中的文件会在写入完成后读取。若网络上的文件夹读取失败，请保存到测量电脑的本地磁盘并监视该文件夹。

## 报告错误

### 报告错误时应发送什么？

问题往往无法在作者的环境中重现，因此请附上：

- 当时的参数文件（**文件 (File) → 保存参数 (Save parameter)**），
- 出现问题时的图像文件，以及
- 错误信息（截图即可）和 IPAnalyzer 的版本。

请通过 [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues) 报告。

## 常见误解

| 误解 | 实际情况 |
|---|---|
| 先载入参数文件，再打开图像 | 打开图像时会切换为该格式所记忆的值。请先打开图像，再载入参数文件 |
| **获取所有序列图像的图谱 (Get Profiles for all sequential images)** 可一次处理多个文件 | 它用于一个文件中的多帧。多个文件请使用宏 |
| 保存谱线需要 PDIndexer | 仅用 IPAnalyzer 即可保存到文件（"获取图谱"之后 (After "Get Profile") 选项卡） |
| CSV 的第三列是另一条谱线 | 它是强度的计数误差 |
| 求和 (Summation) 能改善 S/N | S/N 与平均 (Average) 相同；只有误差估计不同 |
| 相机长度和像素尺寸都能由一幅图像确定 | 不能由一幅图像同时确定；请将像素尺寸固定为产品目录值 |
| 翻转和旋转只改变显示 | 它们也会影响积分和图像保存 |
| 发送到 PDIndexer 时会对谱线进行 Lorentz 偏振校正 | PDIndexer 仅在计算衍射线强度时考虑偏振；谱线本身不会被修改 |
