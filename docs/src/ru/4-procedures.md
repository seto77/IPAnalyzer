# Процедуры

На этой странице показан ход типичных задач. Описание отдельных инструментов см. в разделе [Инструменты](3-tools.md).

## Основной порядок работы (концентрическое интегрирование)

1. **Загрузите изображение**: Файл → Прочитать изображение (File → Read image) (или перетаскиванием).
2. **Задайте источник**: задайте элемент/переход или длину волны в разделе **Источник волн (Wave source)** окна свойств.
3. **Задайте условия детектора**: задайте длину камеры, размер пикселя, положение центра (приблизительно) и при необходимости наклон φ, τ в разделе **Условия детектора (Detector condition)**.
4. **Найдите центр**: автоматически определите центр пучка кнопкой **Найти центр (Find Center)** на панели инструментов (диапазон поиска задаётся на вкладке «Разное» (Miscellaneous)).
5. **Замаскируйте рефлексы**: удалите рефлексы монокристалла и т. п. с помощью **Маскировать рефлексы (Mask Spots)**. При необходимости маскируйте вручную в режиме **Ручной режим (Manual Mode)**.
6. **Проверьте настройки интегрирования**: выберите целевую область в разделе **Область интегрирования (Integral Region)**, а в разделе **Свойства интегрирования (Integral Property)** выберите **Концентрическое интегрирование (Concentric integration)** с единицей оси и **Старт / Конец / Шаг (Start / End / Step)**.
7. **Проинтегрируйте изображение**: получите профиль командой **Получить профиль (Get Profile)**. Сохранение и отправка настраиваются на вкладке **После «Получить профиль» (After "Get Profile")** (сохранение в CSV, отправка в PDIndexer и т. д.).

Для последовательных изображений перед шагами 5–7 выберите кадр в окне [Последовательное изображение (Sequential image)](3-tools.md). Для анализа по азимуту используйте **Анализ с азимутальным делением (Azimuthal Division Analysis)** в раскрывающемся списке **Получить профиль (Get Profile)** (кольца делятся на секторы, и каждый сектор интегрируется) или **Радиальное интегрирование (Radial integration)** в разделе **Свойства интегрирования (Integral Property)** (профиль азимут–интенсивность).

Если длина камеры, длина волны или наклон неизвестны, сначала откалибруйте их по изображению эталонного образца, как описано в следующем разделе, примените полученные значения, а затем интегрируйте изображения образца.

## Определение параметров: геометрическая калибровка по эталонному образцу (метод двух кассет)

Если длина камеры или длина волны неизвестна, оптимизируйте геометрические параметры по дифракционным кольцам эталонного материала (по умолчанию CeO2 и т. д.) с помощью инструмента [Поиск параметров (геометрический)](3-tools.md).

1. Загрузите **Первичное изображение (Primary image)** (эталонный образец при одной длине камеры) кнопкой **Открыть (Open)**, найдите центр и отобразите пики командой **Получить профиль (Get Profile)**.
2. Перетаскивание маркера дифракционной линии в области профиля (Profile View) автоматически обновляет оценку длины камеры.
3. Таким же образом загрузите **Вторичное изображение (Secondary image)** (тот же эталонный образец при другой длине камеры) и введите **разность длин камеры** \(\Delta L = L_\mathrm{Secondary} - L_\mathrm{Primary}\) (mm) (например, +20, если Primary снято при 100 mm, а Secondary — при 120 mm). Вторичное изображение необязательно; калибровка работает и только с первичным изображением.
4. В **Список пиков (Peak List)** выберите значения d пиков, присутствующих на обоих изображениях (обычно три или более на изображение; при двух изображениях хотя бы один пик должен быть общим. Если уточняется не только длина камеры, **Уточнить! (Refine!)** при числе пиков меньше трёх ничего не делает).
5. Выберите параметры для оптимизации (длина волны, расстояние до плёнки, наклон, размер пикселя, искажение пикселя, положение центра, сферическая коррекция).
6. Запустите **Уточнить! (Refine!)**. Уточнение автоматически останавливается после заданного числа повторений (по умолчанию 12). Проверив результат, скопируйте его в главную форму кнопкой **Уточнённые параметры => Главная форма (Refined parameters => Main form)**.

!!! note "Примечание"
    Использование двух изображений («двойная кассета») облегчает раздельное определение длины камеры и длины волны.

## Определение параметров: оптимизация полным перебором (эталонный образец)

Если геометрическая оптимизация плохо сходится, выполните исчерпывающий поиск длины камеры, положения центра, наклона и при необходимости длины волны с помощью инструмента [Поиск параметров (полный перебор)](3-tools.md). Подробное пошаговое описание со снимками экрана см. в разделе [Поиск параметров (полный перебор)](6-find-parameter.md).

1. Загрузите одно изображение эталонного образца в главную форму, откройте «Найти параметр (полным перебором)» (Find parameter (brute force)) и выберите соответствующий эталон.
2. Грубо выставьте положение центра в главной форме (поможет «Найти центр» (Find Center)).
3. Выберите оптимизируемые величины и введите ширину шага **Начальный шаг (Initial step)** (с центром в текущем значении) и число шагов в каждую сторону (**Диапазон поиска (Search range)**). Для плоского детектора размер пикселя не является целью поиска. Численные примеры см. в разделе [Поиск параметров (полный перебор)](6-find-parameter.md).
4. Установка в **Область интегрирования (Integral Region)** режима щели (**Прямоугольник (Rectangle)**) с узкой шириной полосы помогает подавить шум.
5. Запустите поиск кнопкой **Оптимизировать (Optimize)**. В каждом цикле принимается комбинация с наименьшим значением критерия R, и она автоматически записывается в параметры главной формы.

## Автоматическая обработка (Auto Procedure)

Автоматически обрабатывайте изображения, поступающие в папку, например во время эксперимента. Подробности см. в разделе [Инструменты](3-tools.md).

1. Выберите отслеживаемую папку кнопкой **Задать (Set)**.
2. При необходимости отбирайте файлы по **number matching** (число в конце имени файла) или по **Ключевое слово (keyword)**.
3. Включите **After Loading Image, Execute "Auto"** и выберите из списка: Авто контраст (Auto Contrast) / Найти центр (Find Center) / Маскировать рефлексы (Mask Spots) / Получить профиль (Get Profile) / выполнение макроса (Execute Macro).
4. Наконец, включите **Автоматически загружать новые изображения (Automatically load new images)**, чтобы начать отслеживание (без папки его нельзя включить; используются условия по номеру/ключевому слову, действующие в момент начала отслеживания). После этого последовательность выполняется автоматически каждый раз, когда поступает подходящее изображение.

## Сценарные процедуры (макросы на основе Python)

Обработку с циклами и условиями можно записать в виде [макроса](5-macro/index.md). Хорошей отправной точкой служат примеры макросов, показываемые с помощью **Показать примеры (Show samples)** в редакторе макросов.

- Загрузить изображение, задать источник и детектор (центр, длина камеры, пиксели) и подогнать отображение.
- Задать условия концентрического интегрирования (старт, конец, шаг, единица), выполнить одномерное преобразование и сохранить в CSV.
- Пакетно обработать несколько файлов, сохраняя CSV рядом с каждым изображением.
- Обработать многокадровое изображение покадрово.
- Разделить кольцо Дебая на N секторов и проанализировать азимутальную зависимость.
- Замаскировать (очистить всё → маскировать рефлексы → маскировать область ловушки пучка → сохранить маску) и выполнить одномерное преобразование.
- Вывести зависимость интенсивности от азимута с помощью радиального (cake) интегрирования.
- Включить отправку через буфер обмена, выполнить одномерное преобразование и вызвать именованный макрос в PDIndexer (например, подгонку пиков).

Написанные макросы можно сохранять, вызывать по имени, а также запускать из автопроцедуры (Auto Procedure).
