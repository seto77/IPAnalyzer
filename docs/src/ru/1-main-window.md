# Главное окно

Главное окно — первый экран, который появляется при запуске IPAnalyzer. В нём собраны отображение загруженного дифракционного изображения, основные операции (поиск центра, маскирование рефлексов, интегрирование в одномерный (1D) профиль) и точки входа в настройки параметров детектора.

Окно в общих чертах состоит из меню и панели инструментов вверху, области отображения изображения в центре, вертикальной панели инструментов справа и области графиков внизу.

## Центральная область

### Отображение изображения

Здесь отображается загруженное изображение. В зависимости от положения указателя мыши над изображением показываются реальные координаты (mm), координаты изображения (pix), расстояние от центра R (mm), угол рассеяния 2θ, значение d, азимут χ и интенсивность. Пурпурная метка × обозначает положение прямого пятна (центра).

Состояния пикселей показываются разными цветами.

| Цвет | Значение |
| --- | --- |
| Голубой | Маскированный рефлекс |
| Зелёный | Область, исключённая из интегрирования (задаётся в **Область интегрирования (Integral Region)**) |
| Пурпурный | Угловая область, исключённая из интегрирования (задаётся в **Свойства интегрирования (Integral Property)**) |
| Синий | Пиксель с интенсивностью ниже порога (задаётся в **Область интегрирования (Integral Region)**) |
| Красный | Пиксель с интенсивностью выше порога |

### Операции мышью

В обычном режиме:

- Двойной щелчок левой кнопкой: перемещает центр в точку щелчка.
- Щелчок средней кнопкой: запускает поиск центра, начиная с точки щелчка.
- Перетаскивание правой кнопкой: увеличивает выделенную область.
- Щелчок правой кнопкой: уменьшает масштаб.
- Ctrl + перетаскивание правой кнопкой: выбирает прямоугольную область, для которой вычисляется статистическая информация.

Двойной щелчок левой кнопкой и щелчок средней кнопкой работают, только когда **Зафиксир. центр (Fix Center)** выключен.

В режиме **Ручной режим (Manual Mode)** щелчок левой кнопкой маскирует, а щелчок правой кнопкой снимает маску. Форма и размер маски задаются на панели инструментов и в свойствах.

### Вспомогательные виды и информация об изображении

Рядом с центральной областью находятся вспомогательные виды. Можно переключаться между **Всё изображение (Whole image)** и **Около центра (Near center)**: в виде всего изображения текущий диапазон отображения отмечен жёлтой рамкой, а вид около центра показывает увеличенное изображение.

**Информация об изображении (Image Information)** показывает разрешение изображения, максимальную интенсивность, суммарную интенсивность, данные заголовка и т. д.

### Элементы настройки отображения

Элементы, которые настраивают вид изображения:

- **Градиент (Gradient)**: инверсия тонов.
- **Шкала яркости (Brightness scale)**: логарифмическая / линейная.
- **Цветовая шкала (Color scale)**: оттенки серого / цвет.
- **Масштабная линия (Scale line)**: отображение масштабных линий (нет / грубые / средние / мелкие).
- **Авто контраст (Auto Contrast)** / **Сброс контраста (Reset Contrast)**, а также явное задание минимальной/максимальной интенсивности.
- Кнопки увеличения (×1, ×2, ×4, ×1/2, ×1/4, ×1/8, ×1/16).

## Нижняя область

В нижней области есть три графика/вида на вкладках.

- **Частота интенсивности (Frequency of Intensity)**: распределение интенсивности всех пикселей в двойном логарифмическом масштабе. Масштабируется мышью.
- **Преобразованный профиль (Converted Profile)**: дифракционный профиль, полученный командой **Получить профиль (Get Profile)**. Масштабируется мышью.
- **Статистическая информация (Statistical Information)**: статистика для прямоугольной области (X1,Y1)–(X2,Y2), выбранной перетаскиванием правой кнопкой с Ctrl на изображении. Если загружено последовательное изображение, можно также сравнить статистику той же области в других кадрах.

## Меню

Строка меню состоит из пунктов **Файл / Инструменты / Свойства / Параметры / Язык / Макрос / Справка** (File / Tool / Property / Option / Language / Macro / Help).

### Файл (File)

- **Прочитать изображение (Read image)**: открывает дифракционное изображение. Поддерживаемые форматы см. в разделе [Обзор](0-overview.md).
- **Сохранить изображение (Save image)**: сохраняет в формате TIFF, PNG, CSV или IPA. TIFF хранит текущие обработанные интенсивности пикселей (после отражения/поворота, вычитания фона и коррекции поляризации), PNG сохраняет отображение (яркость, контраст, маску), а IPA — собственный формат с коррекцией искажений (с метаданными).
- **Прочитать параметр / Сохранить параметр (Read / Save parameter)**: импортирует/экспортирует длину волны, длину камеры, размер пикселя, коррекцию наклона, положение центра и т. д. в виде файла `.prm`.
- **Прочитать маску / Сохранить маску / Очистить маску (Read / Save / Clear mask)**: импортирует/экспортирует маску в виде файла `.mas` или очищает её (маска должна совпадать по разрешению с текущим изображением).
- **Закрыть (Close)**.

Файлы изображений, параметров и масок также можно загрузить, перетащив их в окно.

### Инструменты (Tool)

- **Сбросить частотный профиль (Reset Frequency Profile)**: перестраивает график частоты интенсивности текущего изображения с диапазоном по умолчанию (изображение сохраняется).
- **Калибровать изображение R-AXIS (Calibrate Raxis Image)**: получает таблицу преобразования интенсивности из двух изображений R-AXIS (см. [Инструменты](3-tools.md)).

### Свойства (Property)

Источник излучения (Wave Source) / Условия Imaging Plate (Imaging Plate Condition) / Область интегрирования (Integral Region) / Свойства интегрирования (Integral Property) / Режим ручной маски (Manual Mask Mode) / После «Получить профиль» (After "Get Profile") / Параметры развёрнутого изображения (Unrolled Image Option) / Разное (Miscellaneous). Эти пункты сразу открывают соответствующие вкладки [окна свойств](2-property-windows.md).

### Параметры (Option)

- **Подсказки (ToolTip)**: включает/выключает всплывающие подсказки на кнопках и в меню.
- **Отразить (Flip)**: **По горизонтали (Horizontally)** / **По вертикали (Vertically)**. **Повернуть (Rotate)**: выбор угла поворота. Отражение и поворот применяются к рабочим данным изображения и поэтому влияют также на последующее интегрирование и сохранение изображения (исходный файл на диске не изменяется).
- **Очистить реестр (проверка и перезапуск) (Clear registry (check and restart))**: пункт для устранения неполадок, стирающий сохранённые настройки.

### Язык (Language)

- Выбирает язык интерфейса (11 языков). После подтверждения приложение перезапускается. Настройка сохраняется в реестре.

### Макрос (Macro)

- **Редактор (Editor)**: открывает редактор макросов (см. [Инструменты](3-tools.md) / [Макрос](5-macro/index.md)).

### Справка (Help)

- **Обновления программы (Program Updates)**, **Подсказка (Hint)**, **Лицензия (License)**, **История версий (Version history)**, **Справка (Help)**.
- **Справка (Help)** открывает это онлайн-руководство в браузере по умолчанию, как и нажатие **F1**.
- Нажмите **F1** в любом окне, чтобы открыть соответствующую страницу этого онлайн-руководства.

## Панель операций

Основные операции обработки изображения (подробные параметры — в раскрывающихся списках):

- **Фон (Background)**: в текущей версии эта кнопка отключена. Вычитание фонового изображения настраивается на вкладке **Параметры фона (Background Option)** окна свойств.
- **Найти центр (Find Center)**: определяет центр пучка подгонкой двумерной функцией Pseudo-Voigt (диапазон поиска по умолчанию — ±8 px вокруг центра, задаётся на вкладке «Разное» (Miscellaneous)). Когда кольца показаны с помощью **Нарисовать кольцо (Draw ring)**, центр определяется по кольцу.
- **Зафиксир. центр (Fix Center)**: фиксирует положение центра.
- **Маскировать рефлексы (Mask Spots)**: в пределах каждой радиальной полосы пиксели, интенсивность которых превышает среднее + стандартное отклонение × **Критерий отклонения для «Маскировать рефлексы» (Criterial deviation for "Mask Spots")** (вкладка **Параметры маски (Mask Option)**), обнаруживаются как рефлексы и маскируются вместе с окрестностью. Раскрывающийся список содержит **Маскировать всю область (Mask all area)**, **Инвертировать маску (Invert mask)**, **Ручной режим (Manual Mode)** и т. д.
- **Ручной режим (Manual Mode)**: режим ручной маски. Можно выбрать форму маски (рефлекс (окружность/прямоугольник) / окружность / прямоугольник / многоугольник / сплайн) и размер рефлекса (полуширину).
- **Получить профиль (Get Profile)**: интегрирует изображение в одномерный (1D) профиль. Поддерживаются **Концентрическое интегрирование (Concentric Integration)** (по 2θ) и **Радиальное интегрирование (Radial integration)** (по азимуту). В раскрывающемся списке настраиваются выбор Integral Property/Region, поиск центра и маскирование рефлексов перед интегрированием, отправка в PDIndexer, **Анализ с азимутальным делением (Azimuthal Division Analysis)** (только при концентрическом интегрировании с осью **Угол (Angle)** (2θ); в остальных случаях выводится предупреждение и ничего не выполняется), обработка последовательных изображений и т. д.

## Панель инструментов (прочие инструменты)

Вертикальная панель инструментов справа запускает различные инструменты. Подробности см. в разделе [Инструменты](3-tools.md).

- **Авто процедура (Auto procedure)**
- **Нарисовать кольцо (Draw ring)**
- **Найти параметр (геометрически) (Find parameter (geometrically))** / **Найти параметр (полным перебором) (Find parameter (brute force))**
- **Развернуть изображение (Unroll image)**
- **Окружное размытие (Circumferential blur)**
- **Последовательное изображение (Sequential image)**
