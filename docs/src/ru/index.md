# Руководство IPAnalyzer

## Краткое введение

* **IPAnalyzer** — свободное программное обеспечение под лицензией MIT, которое преобразует двумерные изображения порошковой дифракции (кольца Дебая–Шеррера), записанные на Imaging Plate (IP) или плоскопанельные детекторы CCD/CMOS, в высокоточные одномерные профили 2θ–интенсивность.
* Программа калибрует геометрию измерения — длину камеры, длину волны, наклон детектора и форму пикселя — по кольцам эталонных материалов, поддерживает рентгеновское, электронное и нейтронное излучение и интегрируется с [PDIndexer](https://github.com/seto77/PDIndexer) для последующего анализа пиков.
* Её устройство и возможности следуют программе *PIP*, разработанной Hiroshi Fujihisa в AIST.

## Возможности

* **Широкая поддержка форматов** : Fuji BAS2000/2500/FDL, Rigaku R-AXIS IV/V, ITEX, Bruker CCD, Rayonix, MAR research, Perkin Elmer, ADSC, RadIcon, Rigaku RINT-RAPID II, SMV, MRC, NeXus (`.nxs`), Digital Micrograph 3/4 и общие форматы изображений. Большинство операций ввода-вывода файлов поддерживают перетаскивание (drag & drop).
* **Преобразование изображения в профиль** : концентрическое (радиально усреднённое), радиальное (азимутальное/cake) интегрирование и вычисление развёрнутого изображения с субпиксельным алгоритмом распределения площади, который корректно учитывает наклон детектора и параллелограммную форму пикселей.
* **Калибровка геометрии** : геометрическое (метод двух кассет, double-cassette) уточнение длины волны, длины камеры, размера/искажения пикселя и наклона (φ, τ), а также поиск по сетке полным перебором для трудных данных.
* **Работа с изображениями** : автоматическое определение центра пучка, обнаружение и маскирование рефлексов монокристалла (spot), окружное размытие, наложение колец, калибровка интенсивности изображений R-AXIS и сохранение в формате IPA с сохранением геометрии.
* **Многокадровые данные** : выбор, усреднение или суммирование кадров NeXus (`.nxs`), многостраничных TIFF и других последовательных данных; если кадр содержит сведения об энергии, при его выборе обновляется длина волны.
* **Автоматизация** : автопроцедура (Auto Procedure) с отслеживанием папки и [макрос](5-macro/index.md) с синтаксисом Python для пакетной и сценарной обработки.
* **Интеграция с PDIndexer** : отправка профилей в [PDIndexer](https://github.com/seto77/PDIndexer) через буфер обмена и запуск там именованных макросов.

## Системные требования

Эти требования относятся к сборкам .NET 11 из данного исходного кода. Для опубликованных выпусков используйте требования к среде выполнения, указанные для соответствующего выпуска.

| Пункт | Минимум | Рекомендуется |
|------|---------|-------------|
| OS | Windows с [.NET Desktop Runtime 11.0](https://dotnet.microsoft.com/download/dotnet/11.0) | Windows 11 |
| Память | - | 16 GB или более |
| CPU | - | 8+ ядер (интенсивности изображения хранятся с двойной точностью, а обработка многопоточная) |

## Быстрый старт

1. Скачайте и установите программу из [Releases](https://github.com/seto77/IPAnalyzer/releases/latest).
2. Считайте дифракционное изображение (**Файл (File) → Прочитать изображение (Read image)** или перетаскиванием).
3. Задайте **Источник волн (Wave source)** и **Условия детектора (Detector condition)** (длина камеры, размер пикселя, приблизительный центр) в окне свойств.
4. Если геометрия (длина камеры, длина волны, наклон) неизвестна, сначала откалибруйте её по изображению эталонного образца и примените полученные значения — см. [Процедуры](4-procedures.md).
5. На изображении образца найдите центр, при необходимости замаскируйте рефлексы и нажмите **Получить профиль (Get Profile)**, чтобы получить 1D-профиль.

Полный рабочий процесс см. в разделе [Процедуры](4-procedures.md).
