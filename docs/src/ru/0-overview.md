# Обзор

IPAnalyzer преобразует кольца Дебая–Шеррера, записанные на Imaging Plate (IP) или детекторы CCD/CMOS, в одномерные (1D) дифракционные профили — с высокой точностью и скоростью. Устройство и возможности программы следуют PIP, разработанной Hiroshi Fujihisa в Национальном институте передовой промышленной науки и технологии (AIST).

Основные возможности:

- Поддержка широкого набора форматов изображений (FujiBAS2000/2500, R-AXIS4/5, ITEX, Bruker CCD, IP Display, IPAimage, Fuji FDL, Rayonix, Mar research, Perkin Elmer, ADSC, RadIcon, Rigaku RINT-RAPID II, SMV, MRC, Digital Micrograph 3/4, NeXus (`.nxs`) и общие форматы изображений)
- Рентгеновское, электронное и нейтронное излучение
- Интеграция с PDIndexer
- Полуавтоматический анализ параметров измерения

## Системные требования и установка

### Требования

Эти требования относятся к сборкам .NET 11 из данного исходного кода. Для опубликованных выпусков используйте требования к среде выполнения, указанные для соответствующего выпуска.

- OS: Windows (рекомендуется Windows 11)
- Необходимая среда выполнения: .NET Desktop Runtime 11.0
- Рекомендуемый объём памяти: 16 GB или более
- Рекомендуемый CPU: 8 ядер или более

Внутри программы интенсивно используются многопоточные вычисления, поэтому на CPU с большим числом ядер она работает комфортнее. Интенсивности изображения хранятся внутри программы как числа с плавающей точкой двойной точности.

Программа распространяется под лицензией MIT.

### Установка

1. Скачайте файл, подходящий для вашего ПК, со [страницы выпусков](https://github.com/seto77/IPAnalyzer/releases/latest) на GitHub.
    - `IPAnalyzer-setup.msi`: установщик для обычных (x64) ПК с Windows (рекомендуется). `IPAnalyzerSetup.msi` идентичен ему; это имя сохранено для автообновления со старых версий.
    - `IPAnalyzer-setup_arm64.msi`: установщик для Windows on Arm.
    - `IPAnalyzer-v.<version>.zip` / `IPAnalyzer-v.<version>_arm64.zip`: портативная версия (без установки; среда выполнения .NET включена) для ПК без прав администратора.
2. Для установщика заранее установите [.NET Desktop Runtime 11.0](https://dotnet.microsoft.com/download/dotnet/11.0), а затем запустите скачанный `.msi`.
3. Для портативной версии распакуйте ZIP в папку, доступную пользователю для записи, и запустите `IPAnalyzer.exe` (не запускайте его изнутри средства просмотра ZIP).

## Ориентация осей, наклон IP и форма пикселя

В IPAnalyzer используется правая система координат; начало и направления осей определены следующим образом.

- Точка, в которой рентгеновский или электронный пучок пересекает IP (прямое пятно, direct spot), принимается за начало координат (0, 0, 0), а ось Z совпадает с направлением пучка.
- Если считать размер образца бесконечно малым, расстояние между положением образца и началом координат определяется как длина камеры (Camera Length, CL). Следовательно, образец находится в точке \((0,\ 0,\ -\mathrm{CL})\).
- Ось X совпадает с направлением сканирования считывающего лазера IP, когда IP не наклонена. Поэтому ось Y направлена на экране вниз.
- Наклон IP выражается как поворот вокруг прямой, лежащей в плоскости XY и проходящей через начало координат: поворот на \( \tau \) вокруг прямой, составляющей угол \( \varphi \) с осью X.
- Форма пикселя рассматривается как параллелограмм, описываемый величинами PixSizeX, PixSizeY и \( \xi \). Ненулевое \( \xi \) означает, что начальная позиция сканирования считывающего лазера IP смещена. Программа предполагает, что это смещение постоянно вдоль оси Y.

Длина камеры, \( \varphi \), \( \tau \), размер пикселя и \( \xi \) задаются на вкладке **Условия детектора (Detector condition)** окна свойств (см. [2. Окна свойств](2-property-windows.md)).

### Связь с (WIN)PIP

В IPAnalyzer ось X (направление вправо на изображении IP) поворачивается по часовой стрелке на \( \varphi \), а затем вокруг полученной оси выполняется поворот на \( \tau \). В PIP ось Y (направление вниз на изображении IP) поворачивается против часовой стрелки на \( \beta \), а затем вокруг полученной оси выполняется поворот на \( \Phi \). Поэтому, чтобы преобразовать \((\beta,\ \Phi)\) из PIP в \((\varphi,\ \tau)\) IPAnalyzer, используйте \((\beta,\ \Phi) \rightarrow (270^\circ - \beta,\ \Phi)\).

## Метод интегрирования интенсивности пикселей

Главная задача интегрирования изображения — как распределить между шагами интегрирования интенсивность пикселя, приходящегося на несколько шагов. Это происходит всякий раз, когда диапазон углов рассеяния, покрываемый одним пикселем, охватывает более одного шага по 2θ (тем чаще, чем мельче шаг).

Программа вычисляет пересечения линий, разграничивающих шаги, с пикселем и распределяет интенсивность пропорционально площади пикселя, попадающей в каждый шаг. Чтобы учесть случаи, когда пиксель не является точным квадратом — из-за наклона IP или искажения формы пикселя, — последовательно вычисляются координаты четырёх углов каждого пикселя и определяется его четырёхугольная форма. В принципе это позволяет плавно распределять интенсивность пикселя по шагам, как бы малы ни были шаги.

Этот алгоритм используется не только для обычного интегрирования угол–интенсивность (концентрическое интегрирование, Concentric Integration), но и для интегрирования вдоль окружности (радиальное интегрирование, Radial Integration) и для вычисления развёрнутого изображения (Unrolled Image).
