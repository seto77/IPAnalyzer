# Q&A (часто задаваемые вопросы)

На этой странице собраны самые частые вопросы и моменты, которые легко понять неправильно. Метки приведены в том виде, в каком они отображаются в русском интерфейсе; в скобках указаны английские названия. С вопросами, которых здесь нет, или чтобы сообщить об ошибке, обращайтесь через [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues).

## Установка и запуск

### Появляется только окно свойств; главного окна не видно

Главное окно оказалось за пределами экрана.

1. Наведите указатель на значок IPAnalyzer на панели задач, щёлкните правой кнопкой по эскизу, выберите **Move** (в русской версии Windows — «Переместить»), один раз нажмите клавишу со стрелкой, а затем двигайте мышь.
2. Если это не помогает, закройте IPAnalyzer, откройте редактор реестра (regedit), удалите `HKEY_CURRENT_USER\Software\Crystallography\IPAnalyzer` и снова запустите IPAnalyzer (все настройки вернутся к значениям по умолчанию).

### После обновления по-прежнему работает старая версия / IPAnalyzer больше не запускается

Переустановите программу напрямую из [последнего выпуска](https://github.com/seto77/IPAnalyzer/releases/latest). Если установка не перезаписывает старую версию или программа не запускается, сначала удалите её через «Параметры» Windows, а затем установите снова. Если в новой версии есть проблема, можно установить более старую версию с той же страницы выпусков.

### Хочу использовать программу на ПК без прав администратора или на Windows on Arm

- Без прав администратора используйте портативную версию (`IPAnalyzer-v.<version>.zip`), которая не требует установки и включает среду выполнения .NET.
- На Windows on Arm используйте установщик arm64 (`IPAnalyzer-setup_arm64.msi`) или портативную версию (`IPAnalyzer-v.<version>_arm64.zip`).

Подробности см. в разделе [Установка в Обзоре](0-overview.md#установка).

### При загрузке большого числа кадров возникает ошибка. Сколько нужно памяти?

IPAnalyzer хранит интенсивность каждого пикселя с двойной точностью (8 байт) независимо от исходной разрядности. Например, 5000 изображений размером 1554×516 пикселей требуют около 32 GB только для интенсивностей. Обрабатывайте данные с большим числом кадров на ПК с достаточным объёмом памяти или обрабатывайте их по частям с помощью макроса.

## Чтение изображений

### Файлы моего детектора не читаются

Возможно, формат ещё не поддерживается. Свяжитесь с нами через [Issues](https://github.com/seto77/IPAnalyzer/issues) или с автором и приложите реальный файл (желательно с дифракционной картиной, а не только темновое изображение). Правильность интенсивностей и ориентацию изображения можно проверить только по изображению с картиной. Если загрузка не удалась, ранее загруженное изображение остаётся, и с ним можно продолжать работу.

!!! note "Если у необработанного (raw) изображения неверные ширина и высота"
    Для raw-файлов без заголовка модель детектора и число пикселей определяются по размеру файла. Фактическое число пикселей часто отличается от каталожного значения, поэтому, если определение не удаётся, пришлите файл.

### После загрузки файла параметров и последующего открытия изображения параметры меняются

IPAnalyzer **запоминает такие параметры, как длина камеры, длина волны и размер пикселя, для каждого формата изображения** и переключается на эти значения при открытии изображения. Поэтому загружайте файл параметров (`.prm`) **после открытия изображения**. Форматы с разными расширениями запоминаются отдельно, даже если их содержимое одинаково.

### Нужно ли заново отражать или поворачивать каждое изображение?

Нет. Настройки **Параметры → Отразить / Повернуть (Option → Flip / Rotate)** также запоминаются для каждого формата изображения и автоматически применяются при следующем открытии изображения того же формата. Отражение и поворот влияют также на интегрирование и сохранение изображения (исходный файл не изменяется).

### Как обрабатываются файлы с несколькими кадрами (`.his`, `.nxs`, многостраничные TIFF, …)?

При загрузке такого файла открывается окно **Последовательное изображение (Sequential image)**, в котором можно выбрать отображаемый кадр. Чтобы проинтегрировать их вместе, используйте **Получить профили для всех последовательных изображений (Get Profiles for all sequential images)** или **Получить профили для выбранных изображений (Get Profiles for selected images)** в раскрывающемся списке **Получить профиль (Get Profile)**. Подробности см. в разделе [Инструменты](3-tools.md#последовательное-изображение-sequential-image).

## Калибровка

### Когда использовать «Найти параметр (геометрически)» (Find parameter (geometrically)), а когда «Найти параметр (полным перебором)» (Find parameter (brute force))?

| | Геометрически | Полным перебором |
|---|---|---|
| Принцип | Делит изображение на секторы, находит положения пиков и определяет центр, наклон и т. д. по эллиптической форме и центрам колец Дебая | Пошагово варьирует параметры и ищет комбинацию, при которой рассчитанные и подогнанные положения пиков совпадают лучше всего |
| Подходящие данные | Кольца видны почти по всей окружности (не менее чем в пяти направлениях) | Записана лишь часть колец, прямое пятно вне изображения, точечные (spotty) кольца |
| Изображения | Одно или два, снятые при разных длинах камеры | Одно |
| Осторожно | Точность падает или уточнение не сходится, если кольца видны не по всей окружности | Нужны достаточно хорошие начальные значения; занимает время |

Порядок действий см. в разделах [Процедуры](4-procedures.md) и [Поиск параметров (полный перебор)](6-find-parameter.md).

### Какой эталонный образец использовать для калибровки?

Подходит образец, дающий гладкие (не точечные) кольца Дебая от мелких зёрен, видимые по возможности по всей окружности. Ориентир — около пяти колец или больше. Только при двух полных кольцах точное определение затруднено, и тогда длина волны или длина камеры должна быть известна. Для калибровки полным перебором выберите эталон из Au / CeO₂ / LaB₆ / Al₂O₃ или выберите **Другой (Other)** и введите параметры решётки.

### Калибровка не сходится / центр продолжает смещаться

- Зафиксируйте значения, которым можно доверять (каталожный размер пикселя, известная длина волны и т. д.), и сократите число уточняемых переменных.
- Сначала выполните грубую подгонку по нескольким кольцам на малых углах, затем добавьте кольца на больших углах.
- Кольцо, анализ которого не удался, может нарушить весь результат. Если одно кольцо выделяется на графике центров колец, удалите его.
- Если подгонка не удаётся при включении колец на больших углах, ограничьтесь пиками, кольца которых ещё видны по всей окружности, расширьте диапазон подгонки и используйте меньше секторов.
- Перед запуском введите как можно более правильные начальные значения.

### Можно ли определить длину камеры и длину волны, только если одна из них зафиксирована?

С эталоном, параметры решётки которого точно известны, обе величины можно определить даже по одному изображению (по отношениям положений колец). Однако **длину камеры и размер пикселя нельзя определить вместе по одному изображению**. Доверьтесь каталожному размеру пикселя и зафиксируйте его. При двух изображениях с известной разностью длин камеры (метод двух кассет) можно уточнить и размер пикселя.

### Прямое пятно не записано / находится вне изображения

Введите положение прямого пятна вручную и снимите флажок **Найти центр перед получением профиля (Find Center before Get Profile)** в раскрывающемся списке **Получить профиль (Get Profile)**. Если пятно находится вне изображения, отрицательные координаты допустимы. Для таких данных используйте калибровку полным перебором.

### Центр, найденный «Найти центр», на несколько пикселей отличается от откалиброванного центра

Они определяются по-разному. **Найти центр (Find Center)** подгоняет прямое пятно вблизи текущего центра двумерной функцией pseudo-Voigt. Калибровка не использует интенсивность прямого пятна; она выводит центр из центров эллипсов нескольких колец Дебая. Если наклон определён правильно, откалиброванный центр можно использовать как есть. Если прямое пятно насыщено, покажите окружность на кольце Дебая с помощью **Нарисовать кольцо (Draw ring)** и нажмите **Найти центр**: тогда центр определяется по кольцу.

### Что такое сферическая коррекция?

Коррекция для детектора, изогнутого подобно сфере. Введите величину, обратную радиусу кривизны, 1/R, в m⁻¹ (на экране показывается как /m). Для плоского детектора используйте 0. Она помогает, когда кольца на больших углах не совпадают, например при большом детекторе, расположенном близко к образцу.

### Как пересчитать значения наклона из другой программы (например, PIP)?

(β, Φ) из PIP пересчитываются в (φ, τ) IPAnalyzer как (270° − β, Φ). Определения см. в разделе [Обзор](0-overview.md#связь-с-winpip).

## Интегрирование и вывод

### Горизонтальная ось результата выглядит неправильно / интенсивность почти постоянна

Проверьте, не выбрано ли **Радиальное интегрирование (картина «торта») (Radial integration (cake pattern))** на вкладке **Свойства интегрирования (Integral Property)** окна свойств. В этом режиме горизонтальной осью профиля является азимут χ. Обычный профиль 2θ–интенсивность получается при **Концентрическое интегрирование (с дисперсией по углу рассеяния) (Concentric integration (scattering angle dispersive))**.

### Хочу сохранить профиль в файл без PDIndexer

На вкладке **После «Получить профиль» (After "Get Profile")** окна свойств задайте в **Сохранить профиль (Save Profiles)** место сохранения (та же папка, что и изображение / выбирать каждый раз) и формат (PDI / CSV / TSV / GSAS). После этого профиль сохраняется при каждом интегрировании.

### Что содержит третий столбец CSV?

Погрешность счёта интенсивности, вычисленную как квадратный корень из суммарной интенсивности пикселей в каждом шаге, рассматриваемой как число отсчётов. Интенсивность во втором столбце пересчитана к эквиваленту геометрии Брэгга–Брентано, поэтому она не равна квадрату третьего столбца. PDIndexer может показывать её в виде планок погрешностей.

### Значения 2θ в CSV имеют только два знака после запятой. Это предел точности?

Нет. Так лишь кажется, потому что интегрирование было настроено, например, с началом 20.00° и шагом 0.01°. Вычисления выполняются с двойной точностью. Точность результата определяется погрешностями входных параметров, таких как длина камеры и длина волны.

### Для последовательных изображений использовать «Среднее» или «Суммирование»?

Отношение S/N в обоих случаях одинаково. **Суммирование (Summation)** даёт правильную оценку погрешностей, поэтому оно рекомендуется для анализа, использующего погрешности, например уточнения по Ритвельду.

### Хочу интегрировать для каждого азимута (каждого сектора)

Включите **Анализ с азимутальным делением (Azimuthal Division Analysis)** в раскрывающемся списке **Получить профиль (Get Profile)**, задайте **Число делений (Number of divisions)** и выполните интегрирование. Создаются общий профиль (имя оканчивается на `-whole`) и по одному профилю на сектор (с добавлением начального угла, например `-000`, `-010`, …). Это работает только при **Концентрическое интегрирование (с дисперсией по углу рассеяния) (Concentric integration (scattering angle dispersive))** и оси **Угол (Angle)** (2θ); при радиальном интегрировании или оси межплоскостного расстояния выводится предупреждение и ничего не выполняется. При слишком большом числе делений данные, отправляемые в PDIndexer, могут оказаться слишком большими.

### Хочу двумерную карту 2θ и азимута χ (развёрнутое изображение)

Используйте **Развернуть изображение (Unroll image)** на панели инструментов. Диапазон и шаг задаются на вкладке **Параметры развёрнутого изображения (Unrolled Image Option)** окна свойств. При **Файл → Сохранить изображение (File → Save image)** формат TIFF сохраняет вычисленные значения с плавающей точкой, а PNG — то, что показано на экране.

### Хочу получить сумму или среднюю интенсивность прямоугольной части изображения

Выделите прямоугольник перетаскиванием правой кнопкой с Ctrl на изображении. Статистика появится на вкладке **Статистическая информация (Statistical Information)** внизу. Для последовательных изображений ту же область можно сравнить между кадрами.

### Темновое изображение становится ярче к краям на больших углах

Если в разделе **Источник волн (Wave source)** окна свойств включено **Коррекция линейной поляризации (т.е. линейно поляризованное → неполяризованное) (Correct linear polarization (i.e., linear polarized → unpolarized))**, коррекция применяется и к сигналам, не связанным с рентгеновским излучением (темновой ток, электронный шум), и сторона больших углов становится ярче. Для темновых изображений выключите её.

### Хочу вычесть темновое (фоновое) изображение

На вкладке **Параметры фона (Background Option)** окна свойств зарегистрируйте текущее изображение как фон и задайте коэффициент. После этого оно автоматически вычитается из изображений того же размера. Подробности см. в разделе [Окна свойств](2-property-windows.md).

## Пакетная обработка и макросы

### Хочу проинтегрировать много файлов сразу

**Получить профили для всех последовательных изображений (Get Profiles for all sequential images)** предназначено для нескольких кадров в одном файле. Для обработки нескольких файлов используйте [макрос](5-macro/index.md). Среди [примеров](5-macro/2-examples.md) есть макрос, который по очереди интегрирует выбранные файлы и сохраняет файлы CSV. Перед его запуском откройте одно изображение и загрузите файл параметров (см. [запоминание параметров](#после-загрузки-файла-параметров-и-последующего-открытия-изображения-параметры-меняются)).

### Хочу вызывать часто используемый макрос из меню

Дайте макросу имя и добавьте его в редакторе макросов; после этого его можно вызвать из меню **Макрос (Macro)** главного окна.

### Хочу интегрировать изображения по мере их поступления во время измерения

Отслеживайте папку с помощью [автопроцедуры (Auto procedure)](3-tools.md#автопроцедура-auto-procedure). Файлы, которые ещё записываются, считываются после завершения записи; файл, который всё ещё заблокирован примерно через 50 с, повторно проверяется при последующих сканированиях, а через 10 минут после первого обнаружения от него отказываются. Если чтение из папки в сети не удаётся, сохраняйте данные на локальный диск измерительного ПК и отслеживайте эту папку.

## Сообщение об ошибке

### Что приложить к сообщению об ошибке?

Проблему часто не удаётся воспроизвести в среде автора, поэтому приложите:

- файл параметров на тот момент (**Файл → Сохранить параметр (File → Save parameter)**),
- файл изображения, с которым возникла проблема, и
- сообщение об ошибке (подойдёт снимок экрана) и версию IPAnalyzer.

Сообщайте через [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues).

## Частые заблуждения

| Предположение | На самом деле |
|---|---|
| Сначала загрузить файл параметров, затем открыть изображение | При открытии изображения программа переключается на значения, запомненные для его формата. Сначала откройте изображение, затем загрузите файл параметров |
| **Получить профили для всех последовательных изображений (Get Profiles for all sequential images)** обрабатывает несколько файлов сразу | Это для нескольких кадров в одном файле. Для нескольких файлов используйте макрос |
| Для сохранения профиля нужен PDIndexer | IPAnalyzer сам может сохранять в файл (вкладка «После «Получить профиль»» (After "Get Profile")) |
| Третий столбец CSV — это другой профиль | Это погрешность счёта интенсивности |
| Суммирование улучшает S/N | S/N такое же, как при усреднении; различается только оценка погрешности |
| Длину камеры и размер пикселя можно определить по одному изображению | Вместе по одному изображению нельзя; зафиксируйте размер пикселя на каталожном значении |
| Отражение и поворот меняют только отображение | Они влияют также на интегрирование и сохранение изображения |
| При отправке в PDIndexer к профилю применяется коррекция Лоренца–поляризации | PDIndexer учитывает поляризацию только для интенсивностей рассчитанных дифракционных линий; сам профиль не изменяется |
