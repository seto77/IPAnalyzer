# Приложение A5. Фактор рассеяния

В текущей версии отражения и структурные факторы кристалла показываются на вкладке **Рефлексы (Reflections)** окна **Взаимодействие пучка с веществом (Beam Interaction)** (оно заменило прежнее окно Scattering Factor). На этой вкладке перечисляются разрешённые кристаллографические плоскости (отражения) выбранного кристалла и для каждой вычисляются **структурный фактор** и интенсивность дифракции. Тип излучения (рентгеновское, электронное или нейтронное) можно переключать, поэтому структурные факторы одного и того же кристалла можно сравнивать для разных дифракционных методов.

В IPAnalyzer окно открывается из окна кристалла, в котором задаётся эталонный кристалл для калибровки параметров (окно кристалла, открываемое кнопкой **Задать кристалл (Set crystal)** в инструменте [Поиск параметров (геометрический)](../3-tools.md), или панель кристалла в разделе [6. Поиск параметров (полный перебор)](../6-find-parameter.md)): нажмите кнопку **Взаимодействие пучка (Beam interaction)** или выберите **Взаимодействие пучка (Beam Interaction)** в контекстном меню панели кристалла.

![Окно «Взаимодействие пучка с веществом» (вкладка «Рефлексы»)](../../assets/references/beam-interaction-reflections-en.png)

Полоса в верхней части окна выбирает падающий пучок, а вкладка **Рефлексы (Reflections)** под ней показывает список отражений (верхняя часть) и штриховую диаграмму тех же отражений (нижняя часть). Список пересчитывается сразу при каждом изменении условия. Остальные вкладки (**Ослабление & перенос (Attenuations & transport)**, **Факторы рассеяния (Scattering factors)**, **Флуоресценция (Fluorescence)**) для IPAnalyzer не нужны; о них см. [Взаимодействие пучка (Beam Interaction) в руководстве ReciPro](https://seto77.github.io/ReciPro/3-beam-interaction/).

## Сочетания клавиш и мыши

В этом окне нет особых сочетаний клавиш или действий мыши. <kbd>F1</kbd> открывает эту страницу руководства, а **Копировать (Copy)** экспортирует таблицу отражений в виде текста, который можно вставить в электронную таблицу.

## Пучок и длина волны

- **X-ray / Electron / Neutron** : атомные факторы рассеяния различаются в зависимости от типа падающего пучка, поэтому он переключается здесь.
- Для **X-ray** выбор **Element** (материала анода) и характеристической линии (Kα и т. д.) автоматически задаёт длину волны этого характеристического рентгеновского излучения.
- **Energy** (keV) и **Wavelength** (Å) связаны: при задании одной величины обновляется другая, и обе используются для вычисления 2θ каждого отражения.
- **Unit** (**Å** / **nm**) переключает единицу длины для межплоскостного расстояния и подобных величин.

---

## Параметры вкладки «Рефлексы»

- **Интенсивности порошковой дифракции (оптика Брэгга–Брентано) (Powder diffraction intensities (Bragg-Brentano optics))** : вычисляет относительную интенсивность как интенсивность порошковой дифракции (Брэгга–Брентано), $I \propto m\,\lvert F\rvert^2 / V^2 \times L$, где $m$ — кратность, $V$ — объём ячейки, а $L = (1+\cos^2 2\theta)/(\sin 2\theta\,\sin\theta)$ (фактор Лоренца–поляризации) для рентгеновского излучения или $L = 1/(\sin 2\theta\,\sin\theta)$ (только фактор Лоренца) для электронов и нейтронов. Отражения, недостижимые для пучка (d < λ/2), получают интенсивность 0. Если параметр выключен, показывается интенсивность структурного фактора $\lvert F\rvert^2$. При включении этого параметра также включаются **Скрыть эквивалентные плоскости (Hide equivalent planes)** и **Скрыть запрещённые плоскости (Hide prohibited planes)**, и они становятся недоступными (серыми).
- **Скрыть эквивалентные плоскости (Hide equivalent planes)** (по умолчанию включено) : объединяет кристаллографически эквивалентные плоскости в одну запись. Столбец **Multi.** показывается только при включённом параметре.
- **Скрыть запрещённые плоскости (Hide prohibited planes)** (по умолчанию включено) : исключает плоскости, систематически погашенные по правилам погасаний. Когда параметр выключен, столбец **Condition** показывает условие(я) отражения, запрещающие каждую погашенную плоскость.
- **d-spacing cutoff >** (по умолчанию 1 Å) : исключает отражения с межплоскостным расстоянием меньше этого значения (единица длины следует **Unit**).

## Список отражений

Каждая строка соответствует одному отражению (или группе симметрично эквивалентных плоскостей).

| Столбец | Значение |
|------|------|
| **h, k, l** | индексы Миллера |
| **Multi.** | кратность (число симметрично эквивалентных плоскостей) |
| **d (Å)** | межплоскостное расстояние |
| **q (2π/d)** | модуль вектора рассеяния |
| **2θ (°)** | угол дифракции для выбранной длины волны |
| **F_real** | действительная часть структурного фактора |
| **F_inv** | мнимая часть структурного фактора |
| **\|F\|** | амплитуда структурного фактора ($= \sqrt{F_\text{real}^2 + F_\text{inv}^2}$) |
| **F^2** | интенсивность структурного фактора ($\lvert F\rvert^2$) |
| **Rel. Int. (%)** | относительная интенсивность; самое сильное отражение принимается за 100 |
| **Condition** | условие(я) погасания, которым не удовлетворяет плоскость (показывается только при выключенном **Скрыть запрещённые плоскости (Hide prohibited planes)**) |

Под таблицей те же отражения изображены в виде штриховой диаграммы, причём самые сильные пики подписаны своими *hkl*. Переключатель выбирает горизонтальную ось из **2θ**, **d** и **Q** ($= 4\pi\sin\theta/\lambda$), **Log I** переключает ось интенсивности между линейной и логарифмической шкалой, а поля **Range** задают отображаемый диапазон.
