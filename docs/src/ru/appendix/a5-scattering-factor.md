# Приложение A5. Фактор рассеяния

**Scattering Factor** перечисляет разрешённые кристаллографические плоскости (отражения) выбранного кристалла и вычисляет для каждой **структурный фактор** и интенсивность дифракции. Тип излучения (рентгеновское, электронное или нейтронное) можно переключать, поэтому структурные факторы одного и того же кристалла можно сравнивать для разных дифракционных методов.

В текущей версии этот список находится на вкладке **Рефлексы (Reflections)** окна **Взаимодействие пучка (Beam interaction)** в окне кристалла (сами атомные факторы рассеяния — на вкладке **Факторы рассеяния (Scattering factors)** того же окна). Описанные ниже экраны и элементы основаны на прежнем окне Scattering Factor.

В IPAnalyzer это вложенное окно открывается из **окна кристалла (Crystal window)** (CrystalControl, используемого в разделе [4. Процедуры](../4-procedures.md) для геометрической калибровки и в разделе [6. Поиск параметров (полный перебор)](../6-find-parameter.md)).

![Фактор рассеяния](../../assets/cap-en-auto/FormScatteringFactor.png)

Условия расчёта находятся в верхней части окна, а список отражений — в нижней. Список пересчитывается сразу при каждом изменении условия.

## Сочетания клавиш и мыши

В этом окне нет особых сочетаний клавиш или действий мыши. <kbd>F1</kbd> открывает эту страницу руководства, а **Copy to clipboard** экспортирует всю таблицу отражений в виде текста, который можно вставить в электронную таблицу.

---

## Wave Length Control

- **X-ray / Electron / Neutron** : атомные факторы рассеяния различаются в зависимости от типа падающего пучка, поэтому он переключается здесь.
- Для **X-ray** выбор **Element** (материала анода) и характеристической линии (Kα и т. д.) автоматически задаёт длину волны этого характеристического рентгеновского излучения.

![Wave Length Control](../../assets/cap-en-auto/FormScatteringFactor.panel3.waveLengthControl1.png)

- **Energy (keV)** и **Wavelength (Å)** связаны друг с другом.
- Эта энергия или длина волны используется для вычисления 2θ (угла дифракции). Для рентгеновского излучения её также можно задать выбором элемента и типа линии.

---

## Параметры отображения и расчёта

- **Интенсивности порошковой дифракции (оптика Брэгга–Брентано) (Powder Diffraction Intensities (Bragg-Brentano Optics))** : вычисляет относительную интенсивность как интенсивность порошковой дифракции (Брэгга–Брентано) с учётом кратности и фактора Лоренца–поляризации. Если выключено, отображается интенсивность структурного фактора.
- **Скрыть эквивалентные плоскости (Hide equivalent planes)** : объединяет кристаллографически эквивалентные плоскости в одну запись.
- **Скрыть запрещённые плоскости (Hide prohibited planes)** : исключает плоскости, интенсивность которых равна нулю по правилам погасаний.
- **Unit (Å / nm)** : переключает единицу длины для межплоскостного расстояния и т. п.
- **d-Spacing Cutoff** : исключает отражения с межплоскостным расстоянием меньше этого значения.

## Список отражений

Каждая строка соответствует одному отражению (или группе симметрично эквивалентных плоскостей).

| Столбец | Значение |
|------|------|
| **h, k, l** | индексы Миллера |
| **Multi.** | кратность (число симметрично эквивалентных плоскостей) |
| **d (Å)** | межплоскостное расстояние |
| **q (2π/d)** | модуль вектора рассеяния |
| **2θ (°)** | угол дифракции для выбранной длины волны |
| **F_real** | действительная часть структурного фактора |
| **F_inv** | мнимая часть структурного фактора |
| **\|F\|** | амплитуда структурного фактора ($= \sqrt{F_\text{real}^2 + F_\text{inv}^2}$) |
| **F^2** | интенсивность структурного фактора ($\lvert F\rvert^2$) |
| **Rel. Int. (%)** | относительная интенсивность; самое сильное отражение принимается за 100 |
