# Приложение

В этом приложении кратко изложены **теоретические основы геометрии и алгоритмов**, которые IPAnalyzer использует при преобразовании двумерного дифракционного изображения (колец Дебая–Шеррера) в высокоточный одномерный профиль. Порядок работы и использование отдельных функций см. в основном руководстве ([0. Обзор](../0-overview.md), [4. Процедуры](../4-procedures.md) и т. д.). Здесь с помощью формул объясняются лежащие в их основе определения системы координат, преобразования координат, методы определения параметров и алгоритм интегрирования.

Содержание основано на прежнем документе `doc/IPAnalyzerAlgorithm.pdf`, входящем в дистрибутив, и на текущей реализации.

## Структура приложения

- **[A1. Геометрия детектора и преобразования координат](a1-geometry.md)** — определение правой системы координат, матрицы поворота, описывающие наклон IP ($\varphi,\ \tau$), и коррекция формы пикселя ($\mathrm{PixSizeX},\ \mathrm{PixSizeY},\ \xi$).
- **[A2. Определение параметров](a2-calibration.md)** — калибровка длины камеры, длины волны, размера пикселя и наклона IP с помощью эталонного материала (метод двух расстояний, метод двух линий, подгонка эллипсов).
- **[A3. Интегрирование изображения](a3-image-integration.md)** — алгоритм разбиения площади, распределяющий интенсивности пикселей по угловым шагам.
- **[A4. Сведения о симметрии](a4-symmetry-information.md)** — симметрия пространственной группы, геометрические расчёты, позиции Уайкова, условия отражения и диаграммы элементов симметрии эталонного кристалла (вложенное окно окна кристалла).
- **[A5. Фактор рассеяния](a5-scattering-factor.md)** — структурные факторы и список отражений эталонного кристалла (рентгеновское, электронное, нейтронное излучение) (вложенное окно окна кристалла).

## Система координат (общий справочный рисунок)

Каждая из следующих страниц исходит из одной и той же системы координат. Начало координат — прямое пятно на IP (точка пересечения пучка с IP), ось $Z$ — направление распространения пучка, а образец находится в точке $(0,\ 0,\ -\mathrm{CL})$.

## Основные параметры

| Символ | Название | Значение |
|------|------|------|
| $\lambda$ | Длина волны (Wave Length) | Длина волны источника. Для характеристического рентгеновского излучения известна; для синхротронного излучения меняется в зависимости от положения монохроматора и должна определяться каждый раз. |
| $\mathrm{CL}$ | Длина камеры (Camera Length) | Расстояние между образцом и началом координат (прямым пятном). Положение образца — $(0,0,-\mathrm{CL})$. На экране соответствует **Длина камеры 1 (Camera Length 1)**; **Длина камеры 2 (Camera Length 2)** — расстояние от образца до детектора по перпендикуляру, которое отличается при наличии наклона $\tau$. |
| $\varphi,\ \tau$ | Коррекция наклона (Tilt Correction) | Наклон IP относительно оптической оси (оси $Z$). $\varphi$ — азимут оси наклона в плоскости XY, а $\tau$ — угол поворота вокруг этой оси. |
| $\mathrm{PixSizeX},\ \mathrm{PixSizeY},\ \xi$ | Размер пикселя (Pixel Size) | Представляет пиксель параллелограммом. $\xi$ — смещение начальной точки сканирования считывающего лазера (угол искажения). |

Длина волны задаётся на вкладке **Источник волн (Wave source)** окна свойств, а длина камеры, наклон и форма пикселя — на вкладке **Условия детектора (Detector condition)** (см. [2. Окна свойств](../2-property-windows.md)).
