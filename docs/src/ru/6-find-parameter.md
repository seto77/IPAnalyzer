# Поиск параметров (полный перебор)

В режиме полного перебора каждый параметр исчерпывающе варьируется (поиск по сетке), чтобы найти значения, которые наилучшим образом обеспечивают:

- малые отклонения (по 2θ) между рассчитанными положениями пиков и положениями, полученными подгонкой, и
- высокие (острые) пики.

Режим эффективен для неполных колец или зашумлённых данных, когда геометрическая оптимизация плохо сходится. Обзор инструмента см. в разделе [Инструменты](3-tools.md), а основной порядок работы — в разделе [Процедуры](4-procedures.md).

## Порядок действий

1. Загрузите данные изображения и параметры, затем нажмите **Найти параметр (полным перебором) (Find parameter (brute force))**.

    ![Запуск поиска параметров (полный перебор)](https://user-images.githubusercontent.com/44538886/180194930-bcefbf4f-7b61-4068-96d1-18bb29109411.png)
    ![Окно калибровки полным перебором](../assets/cap-en-auto/FormFindParameterBruteForce.png)

2. Выберите **эталонный материал**. Если его нет в списке, выберите **Другой (Other)** и введите его вручную.
3. Отобразите профиль кнопкой **Получить профиль (Get Profile)**.
4. Дважды щёлкните линию любого пика, который не нужно использовать для оптимизации, чтобы исключить его.
5. Задайте параметры и нажмите **Оптимизировать (Optimize)**, чтобы начать оптимизацию.

## Настройки

![Настройки](https://user-images.githubusercontent.com/44538886/180196763-e707ea11-5594-4cfe-876b-6d7d28b775e8.png)

### Диапазон подгонки (Fitting Range)

Задаёт угловой диапазон, по которому выполняется подгонка каждого пика.

### Итерация (Iteration)

Задаёт число циклов оптимизации.

### Настройки для каждого параметра

Оптимизация выполняется по отмеченным величинам. Каждый параметр изменяется в заданном диапазоне (**Диапазон поиска (Search range)**) с заданным шагом (**Начальный шаг (Initial step)**).

Например, если длина камеры начинается со 100 mm при Initial step 0.05 mm и Search range 4, то пробуются 9 (= Search range × 2 + 1) значений длины камеры: 99.80, 99.85, 99.90, 99.95, 100.00, 100.05, 100.10, 100.15, 100.20 mm.

Если числа проб для параметров равны N1, N2, N3, …, то общее число проб за цикл равно N1 × N2 × N3 × …. В приведённом примере при четырёх параметрах с Search range 4, 4, 3 и 6 это (4×2+1) × (4×2+1) × (3×2+1) × (6×2+1) = 7371 проба. Иными словами, перебираются 7371 набор параметров, и выбирается комбинация с наименьшим значением критерия R (см. ниже).

!!! warning "Внимание"
    Увеличение **Диапазон поиска (Search range)** резко увеличивает число проб и удлиняет каждый цикл. Используйте его с осторожностью.

## Окно состояния

![Окно состояния](https://user-images.githubusercontent.com/44538886/180197340-efeb9fd5-4e38-4845-939e-1352903502d0.png)

Во время калибровки показывается окно состояния, подобное приведённому выше.

- **Cycle**: номер текущего цикла. По завершении цикла лучший найденный в нём набор параметров становится отправной точкой следующего цикла. Если лучшие параметры совпадают с параметрами в начале цикла, шаг для следующего цикла уменьшается до следующего меньшего значения из заданного ряда (1, 1.3, 1.8, 2.4, 3.2, 4.2, 5.6, 7.5 × 10ⁿ) (например, 0.05 mm → 0.042 mm).
- **Current best values**: лучшие параметры на данный момент.
- **Current steps**: шаг каждого параметра на данный момент.
- **No1, No2, …**: 4 лучших значения критерия с начала поиска (показываются, когда собрано не менее пяти различных значений). Сначала они быстро уменьшаются, а по мере приближения к оптимуму сходятся.

## Значение критерия R

Значение критерия R вычисляется следующим образом.

![Формула значения критерия R](https://user-images.githubusercontent.com/44538886/180198715-04479da0-91dc-489b-b6b5-d80c2f88ea33.png)

Здесь \(2\theta_{\mathrm{calc},i}\) — положение пика \(i\), рассчитанное по текущим параметрам, \(2\theta_{\mathrm{fit},i}\) — положение, полученное подгонкой профиля (оба в градусах), *H* — высота пика за вычетом фона, *W* — вес (100; в текущей версии эта настройка на экране не показывается). Для плоского детектора формула имеет вид:

$$
R = 1000\left[\sum_i \left(2\theta_{\mathrm{calc},i} - 2\theta_{\mathrm{fit},i}\right)^2 + \frac{W}{\sum_i H_i}\right]
$$

R уменьшается по мере уменьшения отклонений положений и роста (обострения) пиков. Сама FWHM в критерии не используется.
