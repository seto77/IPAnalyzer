# Встроенные функции

Методы и свойства, вызываемые из макроса, сгруппированные по пространствам имён под корневым объектом `IPA`. Описания следуют справке редактора макросов (атрибуты `[Help]`); справка в редакторе — основной, актуальный справочник.

## IPA.File

| Член | Описание |
|------|------|
| `GetDirectoryPath(filename="")` | Возвращает полный путь к каталогу. Если `filename` опущен, открывается диалог выбора папки. |
| `GetFileName(message="")` | Открывает диалог выбора файла и возвращает полный путь выбранного файла. |
| `GetFileNames(message="")` | Открывает диалог множественного выбора и возвращает полные пути в виде массива строк. |
| `GetAllFileNames(message="")` | Выбирает папку и возвращает полные пути всех файлов в ней (рекурсивно) в виде массива. |
| `ReadImage(filename="", flag=None)` | Читает файл изображения. Если аргумент опущен, открывается диалог выбора. |
| `ReadImageHDF(filename, flag)` | Читает изображение HDF5. `flag` включает/выключает нормировку. В текущей версии чтение HDF5 (`.h5`) не работает; файлы NeXus (`.nxs`) можно читать с помощью `ReadImage(filename)`. |
| `SaveImage(filename="")` | Сохраняет текущее изображение (устаревший псевдоним; по умолчанию TIFF). |
| `SaveImageAsTIFF(filename="")` | Сохраняет изображение в формате TIFF. |
| `SaveImageAsPNG(filename="")` | Сохраняет изображение в формате PNG. |
| `SaveImageAsIPA(filename="")` | Сохраняет изображение в формате IPA. |
| `SaveImageAsCSV(filename="")` | Сохраняет изображение в формате CSV. |
| `ReadParameter(filename="")` | Читает файл параметров. |
| `SaveParameter(filename="")` | Сохраняет текущие параметры. |
| `ReadMask(filename="")` | Читает файл маски. |
| `SaveMask(filename="")` | Сохраняет текущую маску. |

Для всех методов чтения/сохранения пропуск имени файла или недопустимое имя приводит к открытию диалога выбора.

## IPA.Wave

| Член | Описание |
|------|------|
| `SetWaveLength(wavelength)` | Задаёт длину волны падающего пучка (в nm). |
| `WaveLength` | Задаёт/возвращает длину волны (в nm). |
| `WaveSource` | Задаёт/возвращает источник в виде целого числа. 0: нет, 1: рентгеновское, 2: электронное, 3: нейтронное излучение. |
| `XrayLine` | Задаёт рентгеновскую линию в виде целого числа (только запись). 0: Kα, 1: Kα1, 2: Kα2. |

## IPA.Detector

| Член | Описание |
|------|------|
| `SetCenter(x, y)` | Задаёт положение центра (прямого пятна) (в пикселях). |
| `SetCameraLength(length)` | Задаёт длину камеры (в mm). |
| `CenterX` | Задаёт/возвращает координату X положения центра (в пикселях). |
| `CenterY` | Задаёт/возвращает координату Y положения центра (в пикселях). |
| `CameraLength` | Задаёт/возвращает длину камеры (в mm). |
| `PixelSizeX` | Задаёт/возвращает размер пикселя по X (ширину пикселя) (в mm). |
| `PixelSizeY` | Задаёт/возвращает размер пикселя по Y (высоту пикселя) (в mm). |
| `PixelKsi` | Задаёт/возвращает скос пикселя ξ (в градусах). |
| `TiltPhi` | Задаёт/возвращает наклон φ (в градусах). |
| `TiltTau` | Задаёт/возвращает наклон τ (в градусах). |

## IPA.Image

| Член | Описание |
|------|------|
| `NegativeGradient` | True/False. Отображать изображение с негативным градиентом (пара к `PositiveGradient`). |
| `PositiveGradient` | True/False. Отображать изображение с позитивным градиентом (пара к `NegativeGradient`). |
| `LinearScale` | True/False. Отображать в линейной шкале (пара к `LogScale`). |
| `LogScale` | True/False. Отображать в логарифмической шкале (пара к `LinearScale`). |
| `GrayScale` | True/False. Отображать в оттенках серого (пара к `ColorScale`). |
| `ColorScale` | True/False. Отображать в цветовой шкале (пара к `GrayScale`). |
| `Maximum` | Задаёт/возвращает максимальный уровень яркости (float). |
| `Minimum` | Задаёт/возвращает минимальный уровень яркости (float). |
| `CanvasMagnification` | Задаёт/возвращает увеличение изображения (float). |
| `SetCanvasCenter(x, y)` | Задаёт положение центра холста (в пикселях). |
| `SetCanvasSize(width, height)` | Задаёт размер холста (picture box) (в пикселях). |
| `SetArea(top, bottom, left, right)` | Задаёт область холста границами сверху/снизу/слева/справа (в пикселях). |
| `SetFullArea()` | Задаёт область холста так, чтобы было видно всё изображение. |

## IPA.Mask

| Член | Описание |
|------|------|
| `MaskSpots()` | Маскирует рефлексы (то же, что кнопка «Маскировать рефлексы» (Mask Spots)). |
| `ClearMask()` | Очищает текущие маски. |
| `InvertMask()` | Инвертирует текущее состояние маски. |
| `MaskAll()` | Маскирует всю область. |
| `MaskTop()` | Маскирует верхнюю половину. |
| `MaskBottom()` | Маскирует нижнюю половину. |
| `MaskLeft()` | Маскирует левую половину. |
| `MaskRight()` | Маскирует правую половину. |
| `TakeOver` | Задаёт/возвращает настройку переноса маски (целое число). 0: нет, 1: перенести текущее состояние маски, 2: перенести файл маски. |

## IPA.Profile

| Член | Описание |
|------|------|
| `ConcentricIntegration` | True/False. Концентрическое интегрирование (2θ–интенсивность). |
| `RadialIntegration` | True/False. Радиальное интегрирование (разрез «пиццей»). |
| `AzimuthalDivision` | True/False. Обработка в режиме азимутального деления. |
| `AzimuthalDivisionNumber` | Целое число. Задаёт число делений кольца Дебая. |
| `FindCenterBeforeGetProfile` | True/False. Выполнять «Найти центр» (Find Center) перед «Получить профиль» (Get Profile). |
| `MaskSpotsBeforeGetProfile` | True/False. Выполнять «Маскировать рефлексы» (Mask Spots) перед «Получить профиль» (Get Profile). |
| `SendProfileViaClipboard` | True/False. Отправлять профиль в PDIndexer через буфер обмена. |
| `SaveProfileAfterGetProfile` | True/False. Сохранять профиль после «Получить профиль» (Get Profile). |
| `SaveProfileAsPDI` | True/False. Сохранять в формате PDI. |
| `SaveProfileAsCSV` | True/False. Сохранять в формате CSV. |
| `SaveProfileAsTSV` | True/False. Сохранять в формате TSV. |
| `SaveProfileAsGSAS` | True/False. Сохранять в формате GSAS. Возможно только для концентрического интегрирования с осью 2θ; не записывается, если несколько профилей сохраняются в один файл. |
| `SaveProfileInOneFile` | True/False. Сохранять профили последовательных изображений / азимутального деления в один файл. |
| `SaveProfileAtImageDirectory` | True/False. Сохранять в том же каталоге, что и изображение. |
| `GetProfile(filename="")` | Выполняет одномерное преобразование. Если задан `filename`, он используется как базовое имя, к которому добавляется расширение формата (например, `GetProfile("sample.stl")` при сохранении в CSV даёт `sample.stl.csv`). Если место сохранения задано как «выбирать каждый раз», показывается диалог сохранения. |

## IPA.IntegralProperty

| Член | Описание |
|------|------|
| `ConcentricIntegration` | True/False. Концентрическое интегрирование (2θ–интенсивность). |
| `RadialIntegration` | True/False. Радиальное интегрирование (разрез «пиццей» / картина cake). |
| `ConcentricStart` | Float. Начальное значение концентрического интегрирования. |
| `ConcentricEnd` | Float. Конечное значение концентрического интегрирования. |
| `ConcentricStep` | Float. Шаг концентрического интегрирования. |
| `ConcentricUnit` | Целое число. Единица концентрического интегрирования. 0: угол (deg), 1: межплоскостное расстояние d (Å), 2: длина (mm). |
| `RadialRadius` | Float. Радиус кольца (donut radius) для радиального интегрирования. |
| `RadialWidgh` | Float. Ширина кольца (donut width) для радиального интегрирования. Примечание: в текущей версии член называется `RadialWidgh`. |
| `RadialStep` | Float. Угол сектора (шаг развёртки) для радиального интегрирования. |
| `RadialUnit` | Целое число. Единица радиального интегрирования. 0: угол (deg), 1: межплоскостное расстояние d (Å). |

## IPA.Sequential

| Член | Описание |
|------|------|
| `SequentialImageMode` | True/False. Возвращает, является ли текущий файл последовательным изображением. |
| `Count` | Целое число. Возвращает число изображений. |
| `SelectedIndex` | Целое число. Задаёт/возвращает выбранный индекс (с 0). |
| `SelectedIndices` | Массив целых чисел. Задаёт/возвращает выбранные индексы (для режима множественного выбора). |
| `MultiSelection` | True/False. Задаёт/возвращает режим множественного выбора. |
| `Averaging` | True/False. Задаёт/возвращает режим усреднения. |
| `SelectIndex(index)` | Задаёт один выбранный индекс (выключает множественный выбор). |
| `AppendIndex(index)` | Добавляет один индекс к текущему выбору. |
| `SelectIndices(start, end)` | Задаёт непрерывный диапазон (от start до end включительно). |
| `AppendIndices(start, end)` | Добавляет к текущему выбору непрерывный диапазон (от start до end включительно). |
| `Target_SelectedImages` | True/False. Сделать выбранные изображения целью «Получить профиль» (Get Profile). |
| `Target_AllImages` | True/False. Сделать все изображения целью «Получить профиль» (Get Profile). |
| `Target_TopmostImage` | True/False. Сделать целью «Получить профиль» (Get Profile) только верхнее изображение. |

## IPA.PDI

| Член | Описание |
|------|------|
| `Debug` | True/False. Выполнять макрос в PDIndexer пошагово. |
| `Timeout` | Задаёт/возвращает тайм-аут (в секундах) операции макроса (по умолчанию 30 s). |
| `RunMacro(obj1, obj2, ...)` | Выполняет код, открытый в данный момент в редакторе макросов PDIndexer. Параметры читаются в PDIndexer как `PDI.Obj[0]`, `PDI.Obj[1]`, … |
| `RunMacroName(name, obj1, obj2, ...)` | Выполняет макрос, сохранённый в PDIndexer под именем `name`. Параметры читаются в PDIndexer как `PDI.Obj[0]`, `PDI.Obj[1]`, … |
