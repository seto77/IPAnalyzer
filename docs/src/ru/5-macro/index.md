# Макрос

IPAnalyzer предоставляет функцию **макросов**, которая автоматизирует последовательности операций с помощью Python-подобных скриптов. Она полезна для повторяющейся работы: пакетного одномерного преобразования множества файлов, преобразования форматов, анализа с азимутальным делением.

## Открытие редактора

Откройте редактор макросов через меню **Макрос (Macro)** → **Редактор (Editor)** главного окна. В нём можно редактировать код и выполнять его, в том числе пошагово.

![Редактор макросов](../../assets/cap-en-auto/FormMacro.png)

## Язык

- Доступны управляющие конструкции, такие как `for` / `if` / `while` / `def` / `class`, и арифметика.
- Модуль `math` импортирован заранее, поэтому `math.pi` или `math.sin(...)` можно использовать напрямую без оператора `import`.
- `print()` недоступен. Чтобы проверить значения, используйте **пошаговое выполнение** (Step by step) и следите за изменением переменных на панели отладки.
- Каждая операция IPAnalyzer вызывается из пространства имён под корневым объектом `IPA` (например, `IPA.File`).

## Пространства имён IPA

| Пространство имён | Назначение |
|------|------|
| `IPA.File` | Чтение/запись файлов изображений, параметров и масок; диалоги выбора файлов |
| `IPA.Wave` | Задание источника излучения и длины волны |
| `IPA.Detector` | Задание геометрии детектора: центр, длина камеры, размер пикселя, наклон |
| `IPA.Image` | Управление масштабом отображения, контрастом и областью просмотра |
| `IPA.Mask` | Маскирование рефлексов и областей |
| `IPA.Profile` | Выполнение одномерного преобразования (Get Profile) и настройка сохранения/отправки |
| `IPA.IntegralProperty` | Задание диапазона, шага и единицы концентрического / радиального интегрирования |
| `IPA.Sequential` | Выбор / усреднение / задание целевых кадров многокадрового изображения |
| `IPA.PDI` | Вызов макросов в PDIndexer (интеграция через буфер обмена) |

Список членов см. в разделе [Встроенные функции](1-built-in-functions.md), а конкретные скрипты — в разделе [Примеры](2-examples.md).

!!! tip "Справка в редакторе — основной справочник"
    Описание каждой функции/свойства показывается в справке редактора макросов; это актуальный источник, следующий за версиями программы. Если эта страница расходится со справкой в редакторе, доверяйте последней.

## Примеры макросов

Включите **Показать примеры (Show samples)** в редакторе, чтобы вывести список примеров макросов только для чтения (базовые циклы, математические функции, настройка геометрии, пакетная обработка, азимутальное деление, маскирование, отправка в PDIndexer и т. д.); выключите его, чтобы вернуться к собственным сохранённым макросам. Это удобная отправная точка для адаптации.

## Работа с автопроцедурой (Auto Procedure)

Написанные макросы можно сохранять под именем и вызывать из списка «выполнить после загрузки» [автопроцедуры (Auto Procedure)](../3-tools.md), чтобы макрос автоматически применялся к каждому изображению, поступающему во время эксперимента.
