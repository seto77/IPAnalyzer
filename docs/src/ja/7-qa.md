# Q&A（よくある質問）

これまでに寄せられた質問のうち、多かったものと勘違いしやすいものをまとめました。画面の名前は日本語表示のもので、括弧内は英語表示です。ここに無い質問や不具合の報告は、[GitHub の Issues](https://github.com/seto77/IPAnalyzer/issues) へお寄せください。

## インストール・起動

### 起動しても、プロパティウィンドウだけが出て本体のウィンドウが見えない

本体のウィンドウが画面の外に表示されています。

1. タスクバーの IPAnalyzer のアイコンにカーソルを置き、サムネイルを右クリックして **移動** を選び、矢印キーを 1 回押してからマウスを動かします。
2. それでも戻らないときは、IPAnalyzer を終了した状態でレジストリエディタ（regedit）を開き、`HKEY_CURRENT_USER\Software\Crystallography\IPAnalyzer` を削除してから起動します（すべての設定が初期状態に戻ります）。

### 更新したのに古い版のまま / 更新後に起動しない

[releases ページの最新版](https://github.com/seto77/IPAnalyzer/releases/latest) から直接入れ直してください。上書きで入らない、または起動しない場合は、Windows の設定から一度アンインストールしてからインストールします。新しい版で不具合が出たときは、同じ releases ページから旧版を入れて使うこともできます。

### 管理者権限が無い PC や、Windows on Arm の PC で使いたい

- 管理者権限が無い PC では、インストール不要のポータブル版（`IPAnalyzer-v.<版>.zip`）を使ってください。.NET ランタイムも同梱されています。
- Windows on Arm では、arm64 用のインストーラ（`IPAnalyzer-setup_arm64.msi`）かポータブル版（`IPAnalyzer-v.<版>_arm64.zip`）を使ってください。

詳しくは[概要のインストール](0-overview.md#インストール)を参照してください。

### たくさんのフレームを読み込むとエラーになる。メモリはどれくらい必要か

IPAnalyzer は、元のビット深度に関係なく、画素ごとの強度を倍精度（8 バイト）で保持します。例えば 1554×516 画素の画像 5000 枚では、強度だけで約 32 GB を使います。フレーム数の多いデータは、メモリに余裕のある PC で扱うか、マクロで少しずつ処理してください。

## 画像の読み込み

### 使っている検出器のファイルが読めない

対応していない形式かもしれません。実際のファイル（できればダークだけでなく、回折像が写ったもの）を添えて、[Issues](https://github.com/seto77/IPAnalyzer/issues) か作者へご連絡ください。強度の正しさや上下左右の向きは、回折像が写った画像でないと確かめられません。読み込みに失敗しても、前に読み込んだ画像はそのまま残るので、作業を続けられます。

!!! note "raw 形式の画像の縦横がおかしいとき"
    ヘッダを持たない raw 形式では、ファイルの大きさから検出器の機種と画素数を判定しています。実データの画素数はカタログ値と違うことがよくあるので、判定に失敗した場合もファイルを送ってください。

### パラメータファイルを読み込んでから画像を開くと、パラメータが変わってしまう

IPAnalyzer は、カメラ長・波長・画素サイズなどのパラメータを**画像の形式ごとに記憶**し、画像を開いたときにその形式の値へ切り替えます。そのため、**画像を開いてから**パラメータファイル（`.prm`）を読み込んでください。中身が同じでも、形式（拡張子）が違えば別々に記憶されます。

### 反転・回転は、画像を開くたびにやり直す必要があるのか

いいえ。**オプション → 反転 / 回転 (Option → Flip / Rotate)** の設定も画像の形式ごとに記憶され、同じ形式の画像を次に開いたときにも自動で適用されます。反転・回転は積分や画像の保存にも反映されます（元のファイルは変わりません）。

### 1 つのファイルに入った複数のフレーム（`.his`、`.nxs`、多ページ TIFF など）はどう扱うのか

読み込むと **シーケンシャル画像 (Sequential image)** のウィンドウが開き、フレームを選んで表示できます。**1次元化 (Get Profile)** のドロップダウンにある **シーケンシャル画像中の全てを一次元化 (Get Profiles for all sequential images)** または **選択した画像のみ一次元化 (Get Profiles for selected images)** で、まとめて一次元化できます。詳しくは[各種ツール](3-tools.md#シーケンシャル画像-sequential-image)を参照してください。

## パラメータの校正

### 「パラメータ校正(幾何学的)」と「パラメータ校正 (力ずく)」はどう使い分けるのか

| | 幾何学的 | 力ずく |
|---|---|---|
| 考え方 | 画像を扇形に分けてピーク位置を求め、デバイ環の楕円の形と中心から中心・傾きなどを決める | パラメータを少しずつ動かし、計算したピーク位置とフィットしたピーク位置が最もよく合う組み合わせを探す |
| 向いているデータ | リングがほぼ全周（少なくとも 5 方向）で見えるもの | リングの一部しか写っていない、ダイレクトスポットが画像の外にある、スポット状のリングが多い |
| 画像 | 1 枚、またはカメラ長を変えた 2 枚 | 1 枚 |
| 注意 | 全周が見えないと精度が落ちるか、収束しない | 初期値がかなり近くないとうまくいかない。時間がかかる |

手順は[実際の手順](4-procedures.md)と[パラメータ校正（力ずく）](6-find-parameter.md)を参照してください。

### 校正にはどんな標準試料を使えばよいか

粒が細かく、スポット状でない滑らかなデバイ環が、なるべく全周見えるものが適しています。リングは 5 本以上あるのが目安です。全周が見えるリングが 2 本だけでは精密に決めるのが難しく、波長かカメラ長の一方が既知であることが望まれます。力ずくの校正では、標準物質を Au / CeO₂ / LaB₆ / Al₂O₃ から選ぶか、**その他 (Other)** を選んで格子定数を入力します。

### 校正が収束しない / 中心がどんどんずれていく

- 信頼できる値（カタログ値の画素サイズ、既知の波長など）は固定し、最適化する変数を減らします。
- まず低角の数本のリングで大まかに合わせてから、高角のリングを加えます。
- 解析に失敗したリングが全体を乱していることがあります。リング中心のグラフで 1 本だけ外れたリングがあれば、そのリングを外します。
- 高角まで入れるとフィットできない場合は、全周がぎりぎり見える範囲のピークに絞り、フィッティング範囲を広めに、扇形の分割数を少なめにします。
- 最適化を始める前に、初期値をできるだけ正しく入れておきます。

### カメラ長と波長は、片方を固定しないと決まらないのか

格子定数が正確に分かっている標準物質を使えば、1 枚の画像からでも両方を決められます（複数のリングの位置の比から決まります）。一方、**1 枚の画像では、カメラ長と画素サイズは同時に決められません**。画素サイズはカタログ値を信頼して固定してください。カメラ長の差が分かっている 2 枚の画像（ダブルカセット法）を使えば、画素サイズも最適化できます。

### ダイレクトスポットが写っていない / 画像の外にある

ダイレクトスポットの位置を手で入力し、**1次元化 (Get Profile)** のドロップダウンにある **「１次元化」前に中心位置を検索 (Find Center before Get Profile)** のチェックを外します。画像の外にある場合は、座標が負の値でもかまいません。校正には、力ずくの校正を使ってください。

### 「中心位置 (Find Center)」で求めた中心と、パラメータ校正で求めた中心が数ピクセル違う

求め方が違うためです。**中心位置 (Find Center)** は、現在の中心付近のダイレクトスポットを 2 次元の擬 Voigt 関数でフィットします。パラメータ校正は、ダイレクトスポットの強度を使わず、複数のデバイ環の楕円中心から中心を求めます。傾きを正しく決めておけば、校正で得た中心をそのまま使えます。ダイレクトスポットが飽和しているときは、**リング描画 (Draw ring)** でデバイ環に円を表示した状態で **中心位置 (Find Center)** を押すと、リングをもとに中心を求めます。

### 「球面補正 (Spherical correction)」とは何か

検出器が球面状にたわんでいる効果の補正です。曲率半径 R の逆数 1/R を m⁻¹ 単位で入力します（画面の単位表示は /m）。平面検出器では 0 です。大面積の検出器を試料に近づけた測定で、高角側のリングの位置が合わないときに効果があります。

### 他のソフト（PIP など）の傾きの値は、どう換算するのか

PIP の (β, Φ) は、IPAnalyzer の (φ, τ) = (270° − β, Φ) に換算します。定義は[概要](0-overview.md#winpip-との関係)を参照してください。

## 一次元化・出力

### 一次元化の結果の横軸がおかしい / 強度がほぼ一定に見える

プロパティの **1次元化の条件 (Integral Property)** で、**偏角 (sector angle) 積算 (Radial integration (cake pattern))**（円周方向積分）が選ばれていないか確認してください。このモードでは、横軸が方位角 χ のプロファイルになります。通常の 2θ–強度プロファイルは **散乱角(2θ)積算 (Concentric integration (scattering angle dispersive))** で得られます。

### PDIndexer を使わずに、プロファイルをファイルに保存したい

プロパティの **１次元化後の処理 (After "Get Profile")** タブの **１次元化したプロファイルをファイルとして保存 (Save Profiles)** で、保存先（画像と同じフォルダ / 毎回選択）と形式（PDI / CSV / TSV / GSAS）を設定します。以後、一次元化のたびに保存されます。

### CSV の 3 列目は何か

強度の計数誤差です。各ステップに入った画素強度の合計を計数とみなし、その平方根から求めています。2 列目の強度は Bragg–Brentano 光学系に相当する値に変換してあるので、2 列目の平方根とは一致しません。PDIndexer に送ると誤差棒として表示できます。

### CSV の 2θ が小数第 2 位までしか出ない。これが精度の限界か

いいえ。開始角 20.00°・刻み 0.01° のような条件で積分したので、そう見えるだけです。内部は倍精度で計算しています。結果の精度を決めるのは、カメラ長や波長など入力したパラメータの誤差です。

### シーケンシャル画像の［平均］と［積算］はどちらを使えばよいか

S/N 比はどちらでも同じです。**積算 (Summation)** は誤差を正しく評価できるので、Rietveld 解析など誤差を使う解析には［積算］を勧めます。

### 方位角ごと（扇形ごと）に一次元化したい

**1次元化 (Get Profile)** のドロップダウンで **方位角分割解析 (Azimuthal Division Analysis)** をオンにし、**方位角の分割数 (Number of divisions)** を設定してから一次元化します。全体のプロファイル（名前の末尾が `-whole`）と、扇形ごとのプロファイル（`-000`、`-010` … のように開始角が付く）が作られます。この解析は、**散乱角(2θ)積算 (Concentric integration (scattering angle dispersive))** で横軸が **角度 (Angle)**（2θ）のときだけ実行できます。偏角積算や d 値の横軸では警告が出て実行されません。分割数を多くしすぎると、PDIndexer へ送るデータが大きくなりすぎることがあります。

### 2θ と方位角 χ の 2 次元マップ（切り開き画像）が欲しい

ツールバーの **切り開き (Unroll image)** を使います。範囲と刻みはプロパティの **切り開き画像の設定 (Unrolled Image Option)** タブで設定します。**ファイル → 画像を保存 (File → Save image)** で、TIFF なら計算値を浮動小数点のまま、PNG なら画面の見た目どおりに保存できます。

### 画像の一部の矩形領域について、強度の合計や平均を知りたい

Ctrl キーを押しながら画像を右ドラッグして矩形を選ぶと、下部の **統計情報 (Statistical Information)** タブに統計量が表示されます。シーケンシャル画像では、同じ領域の他のフレームの値も比べられます。

### ダーク画像なのに、高角側の端が明るくなる

プロパティの **線源の設定 (Wave source)** で **偏光補正を行う (Correct linear polarization)** がオンになっていると、X 線によらない信号（ダーク・電気的なノイズ）にも補正がかかり、高角側が明るくなります。ダーク画像を扱うときはオフにしてください。

### ダーク画像（バックグラウンド）を差し引きたい

プロパティの **バックグラウンドオプション (Background Option)** タブで、現在の画像をバックグラウンドとして登録し、係数を設定します。以後、同じ大きさの画像からは自動で差し引かれます。詳しくは[プロパティウィンドウ](2-property-windows.md)を参照してください。

## 一括処理・マクロ

### たくさんのファイルを一度に一次元化したい

**シーケンシャル画像中の全てを一次元化 (Get Profiles for all sequential images)** は、1 つのファイルに入った複数のフレームのための機能です。複数のファイルを処理するには[マクロ](5-macro/index.md)を使ってください。[使用例](5-macro/2-examples.md)に、ファイルを選んで順に一次元化し、CSV で保存する例があります。実行する前に、画像を 1 枚開いてパラメータファイルを読み込んでおきます（[パラメータの記憶](#パラメータファイルを読み込んでから画像を開くとパラメータが変わってしまう)を参照）。

### よく使うマクロをメニューから呼び出したい

マクロエディタで名前を付けてマクロを追加すると、メインウィンドウの **マクロ (Macro)** メニューから呼び出せるようになります。

### 測定中に、届いた画像をその場で一次元化したい

[自動実行 (Auto procedure)](3-tools.md#自動実行-auto-procedure) でフォルダを監視します。書き込み中のファイルは完了を待ってから読み込みます。約 50 秒待ってもロックされていたファイルは後の走査で再び試し、最初に見つけてから 10 分たっても読めなければ諦めます。ネットワーク越しのフォルダで読み込みに失敗する場合は、測定 PC のローカルに保存してから、そのフォルダを監視してください。

## 不具合の報告

### 不具合を報告するとき、何を送ればよいか

作者の環境では再現できないことが多いため、次のものを添えてください。

- そのときのパラメータファイル（**ファイル → パラメータを保存 (File → Save parameter)**）
- 問題が起きた画像ファイル
- エラーメッセージの内容（画面のコピーでもかまいません）と、IPAnalyzer の版

報告は [GitHub の Issues](https://github.com/seto77/IPAnalyzer/issues) へお願いします。

## よくある勘違い

| 思い込み | 実際 |
|---|---|
| パラメータファイルを読み込んでから画像を開けばよい | 画像を開くと、その形式で記憶した値に切り替わる。画像を開いてからパラメータファイルを読み込む |
| **シーケンシャル画像中の全てを一次元化** で複数のファイルを一括処理できる | 1 つのファイルに入った複数フレーム用。複数のファイルはマクロで処理する |
| プロファイルを保存するには PDIndexer が必要 | IPAnalyzer だけでファイルに保存できる（After "Get Profile" タブ） |
| CSV の 3 列目は別のプロファイル | 強度の計数誤差 |
| 積算すると S/N が上がる | S/N は平均と同じ。違うのは誤差の評価 |
| 1 枚の画像からカメラ長と画素サイズを両方決められる | 1 枚では同時に決まらない。画素サイズはカタログ値で固定する |
| 反転・回転は表示だけの操作 | 積分や画像の保存にも反映される |
| PDIndexer に送ると、プロファイルにローレンツ偏光因子の補正がかかる | PDIndexer が偏光を考慮するのは計算上の回折線の強度だけで、プロファイルは加工しない |
