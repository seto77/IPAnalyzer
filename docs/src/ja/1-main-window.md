# メインウィンドウ

メインウィンドウは、IPAnalyzer を起動すると最初に表示される画面です。読み込んだ回折画像の表示、各種演算（中心検索・スポット除外・一次元化）、検出器パラメータの設定への入口がここに集まっています。

画面はおおまかに、上部のメニューとツールバー、中央の画像表示部、右側の縦型ツールバー、下部のグラフ表示部から構成されます。

![IPAnalyzer のメインウィンドウ](../assets/cap-ja-auto/FormMain.png)

## 中央画面

### 画像表示部分

読み込んだ画像を表示します。画像上部には、マウスポインタの位置に応じて、実座標 (mm)、画像座標 (pix)、中心からの距離 R (mm)、散乱角 2θ、d 値、方位角 χ、強度が表示されます。マゼンタ（赤紫）色の × 印はダイレクトスポット（中心）位置を表します。

ピクセルの状態は色で区別して表示されます。

| 色 | 意味 |
| --- | --- |
| 水色 | マスクされたスポット |
| 緑色 | 積算対象外領域（［画像範囲の設定］で設定） |
| 紫色 | 積算対象外の角度領域（［1次元化の条件］で設定） |
| 青色 | 閾値強度以下のピクセル（［画像範囲の設定］で設定） |
| 赤色 | 閾値強度以上のピクセル |

### マウス操作

通常モードでのマウス操作は次のとおりです。

- 左ダブルクリック: 中心位置をクリック点へ更新します。
- 中クリック: クリック点を初期位置として中心位置を検索します。
- 右ドラッグ: 範囲を拡大表示します。
- 右クリック: 縮小表示します。
- Ctrl＋右ドラッグ: 統計情報の対象とする矩形範囲を選びます。

左ダブルクリックと中クリックは、**中心固定 (Fix Center)** がオフのときに働きます。

**マニュアルモード (Manual Mode)** のときは、左クリックでマスク、右クリックでマスク解除になります。マスク形状やサイズはツールバーおよびプロパティで設定します。

### 補助画面・画像情報

中央画面の脇には補助表示があります。**全体表示 (Whole image)** と **中心付近 (Near center)** を切り替えられ、全体表示では現在の表示範囲を黄色の枠で、中心付近では拡大像を表示します。

**画像情報 (Image Information)** には、画像の解像度・最大強度・総強度・ヘッダ情報などが表示されます。

### 表示調整部

画像の見え方を調整するコントロール群です。

- **ポジ/ネガ (Gradient)**: 階調の反転。
- **強度スケール (Brightness scale)**: 対数 / 線形。
- **グレー/カラー (Color scale)**: グレースケール / カラー。
- **目盛 (Scale line)**: 目盛線の表示（なし / 粗 / 中 / 細）。
- **自動コントラスト (Auto Contrast)** / **リセット (Reset Contrast)**、および最小・最大強度の指定。
- 表示倍率ボタン（×1, ×2, ×4, ×1/2, ×1/4, ×1/8, ×1/16）。

## 下部画面

下部にはタブで切り替わる 3 つのグラフ／情報があります。

- **強度頻度 (Frequency of Intensity)**: 全ピクセルの強度分布を両対数で表示します。マウスで拡大できます。
- **変換プロファイル (Converted Profile)**: **1次元化 (Get Profile)** 実行後の回折プロファイルを表示します。マウスで拡大できます。
- **統計情報 (Statistical Information)**: Ctrl キーを押しながら画像を右ドラッグして選んだ矩形領域 (X1,Y1)–(X2,Y2) の統計量を表示します。シーケンシャル画像を読み込んでいる場合は、同じ領域の他フレームの統計も比較表示できます。

## メニュー

メニューバーは **ファイル / ツール / プロパティ / オプション / 言語 / マクロ / ヘルプ (File / Tool / Property / Option / Language / Macro / Help)** で構成されます。

### ファイル (File)

- **画像を読込 (Read image)**: 回折画像を開きます。対応形式は[概要](0-overview.md)を参照してください。
- **画像を保存 (Save image)**: TIFF形式 / PNG形式 / CSV形式 / IPA形式 を選んで保存します。TIFF は現在の処理後の画素強度（反転・回転・バックグラウンド補正・偏光補正を適用した値）、PNG は表示（明るさ・コントラスト・マスク）を保ったまま、IPA は歪み補正済みの独自形式（メタデータ付き）です。
- **パラメータを読込 / 保存 (Read / Save parameter)**: 波長・カメラ長・ピクセルサイズ・傾き補正・中心位置などを `.prm` ファイルで入出力します。
- **マスク領域を読込 / 保存 / クリア (Read / Save / Clear mask)**: マスクを `.mas` ファイルで入出力、または消去します（マスクは現在の画像と同じ解像度が必要）。
- **閉じる (Close)**。

画像・パラメータ・マスクの各ファイルはウィンドウへのドラッグ＆ドロップでも読み込めます。

### ツール (Tool)

- **頻度プロファイルをリセット (Reset Frequency Profile)**: 現在の画像の強度頻度グラフを既定の範囲で作り直します（画像はそのまま）。
- **R-AXIS画像の校正 (Calibrate Raxis Image)**: R-AXIS の画像 2 枚から強度変換表を求めます（[各種ツール](3-tools.md)を参照）。

### プロパティ (Property)

線源の設定 / 検出器の設定 / 画像範囲の設定 / １次元化の条件 / マスク条件 / １次元化後の処理 / 切り開き画像の設定 / その他。これらは[プロパティウィンドウ](2-property-windows.md)の各タブを直接開きます。

### オプション (Option)

- **ツールチップ (ToolTip)**: ボタンやメニューのツールチップ表示の切り替え。
- **反転 (Flip)**: **水平に反転 (Horizontally)** / **垂直に反転 (Vertically)**。**回転 (Rotate)**: 回転角の選択。反転・回転は作業中の画像データに適用され、その後の積分や画像の保存にも反映されます（読み込み元のファイルは変更しません）。
- **レジストリをクリア (チェックで再起動) (Clear registry (check and restart))**: 保存された設定を消去するトラブルシュート用の項目です。

### 言語 (Language)

- 表示言語を選びます（11 言語）。切り替えると確認のうえアプリが再起動します。設定はレジストリに保存されます。

### マクロ (Macro)

- **編集 (Editor)**: マクロエディタを開きます（[各種ツール](3-tools.md) / [マクロ](5-macro/index.md) を参照）。

### ヘルプ (Help)

- **プログラムの更新 (Program Updates)**、**ヒント (Hint)**、**ライセンス (License)**、**バージョン履歴 (Version history)**、**ヘルプ (Help)**。
- **ヘルプ (Help)** は、**F1** キーと同じく、このオンラインマニュアルを既定のブラウザで開きます。
- 各ウィンドウで **F1** キーを押すと、このオンラインマニュアルの該当ページが開きます。

## 演算ツールバー

画像処理の主要操作です（ドロップダウンに詳細オプションがあります）。

- **バックグラウンド補正 (Background)**: 現行版ではこのボタンは無効です。バックグラウンド画像の減算は、プロパティウィンドウの［バックグラウンドオプション］タブで設定します。
- **中心位置 (Find Center)**: 2 次元 Pseudo-Voigt フィッティングでビーム中心を検出します（探索範囲は既定で中心から ±8 px。［その他］タブで設定）。**リング描画 (Draw ring)** でリングを表示している間に押すと、リングに基づいて中心を求めます。
- **中心固定 (Fix Center)**: 中心位置を固定します。
- **スポット検出 (Mask Spots)**: 同じ半径の帯の中で、強度が「平均＋標準偏差×**標準偏差の何倍ずれた時スポットとみなすか (Criterial deviation for "Mask Spots")**（［マスク条件］タブ）」を上回る画素をスポットとして検出し、その周囲も含めてマスクします。ドロップダウンに **全ての領域をマスクする (Mask all area)**・**マスクを反転 (Invert mask)**・**マスクをマニュアル設定 (Manual Mode)** などがあります。
- **マニュアルモード (Manual Mode)**: 手動マスクモード。マスクの形状（スポット（円・矩形）／円／矩形／多角形／スプライン）と、スポットの大きさ（半幅）を指定できます。
- **1次元化 (Get Profile)**: 画像を一次元プロファイルへ積算します。**散乱角積算 (Concentric Integration)**（2θ 基準）と **偏角積算 (Radial integration)**（方位角基準）に対応します。ドロップダウンで、一次元化方法・積算範囲の選択、一次元化前の中心検索・スポット検出の有無、PDIndexer 送信、**方位角分割解析 (Azimuthal Division Analysis)**（散乱角積算で横軸が **角度 (Angle)**（2θ）のときだけ実行できます。それ以外では警告が出て実行されません）、シーケンシャル画像処理などを設定します。
