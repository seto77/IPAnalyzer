# 実際の手順

代表的な作業の流れを示します。各ツールの個別説明は[各種ツール](3-tools.md)を参照してください。

## 基本的な流れ（同心円積分）

1. **画像を読み込む**: ファイル → 画像を読込（またはドラッグ＆ドロップ）。
2. **線源を設定**: プロパティの **線源の設定 (Wave source)** で元素・遷移、または波長を設定します。
3. **検出器条件を設定**: **検出器の設定 (Detector condition)** でカメラ長・画素サイズ・中心位置（おおよそ）・必要なら傾き φ, τ を設定します。
4. **中心を検索**: ツールバーの **中心位置 (Find Center)** でビーム中心を自動検出します（探索範囲は［その他］タブで設定）。
5. **スポットを除外**: **スポット検出 (Mask Spots)** で単結晶反射などを除きます。必要なら **マニュアルモード (Manual Mode)** で手動マスクします。
6. **積分の条件を確認**: **画像範囲の設定 (Integral Region)** で対象領域を、**1次元化の条件 (Integral Property)** で **散乱角(2θ)積算 (Concentric integration (scattering angle dispersive))** と横軸の単位・**開始 / 終了 / ステップ (Start / End / Step)** を設定します。
7. **一次元化**: **1次元化 (Get Profile)** でプロファイルを取得します。保存・送信は **１次元化後の処理 (After "Get Profile")** タブで設定します（CSV 保存、PDIndexer 送信など）。

シーケンシャル画像では、5〜7 の前に[シーケンシャル画像](3-tools.md)でフレームを選びます。方位角ごとの解析には、**1次元化 (Get Profile)** のドロップダウンにある **方位角分割解析 (Azimuthal Division Analysis)**（リングを扇形に分けてそれぞれ一次元化。散乱角積算で横軸が **角度 (Angle)**（2θ）のときだけ実行できます）か、**1次元化の条件 (Integral Property)** の **偏角 (sector angle) 積算 (Radial integration (cake pattern))**（方位角–強度プロファイル）を使います。

カメラ長・波長・傾きが分からないときは、先に次節の手順で標準試料の画像から校正し、得た値を設定してから試料の画像を一次元化します。

## パラメータ決定：標準試料を用いた幾何校正（ダブルカセット法）

カメラ長や波長が未知のとき、標準物質（既定は CeO2 など）の回折リングから幾何パラメータを最適化します。[パラメータ校正（幾何学的）](3-tools.md)を使います。

1. **プライマリ(Primary)画像 (Primary image)**（標準試料、あるカメラ長）を **開く (Open)** で読み込み、中心を検出して **一次元化 (Get Profile)** でピークを表示します。
2. Profile View 上で回折線マーカーをドラッグすると、カメラ長の見積もりが自動で更新されます。
3. **セカンダリ(sencondary)画像 (Secondary image)**（同じ標準試料、別のカメラ長）を同様に読み込み、Primary との**カメラ長の差** \(\Delta L = L_\mathrm{Secondary} - L_\mathrm{Primary}\)（mm）を入力します（例: Primary が 100 mm、Secondary が 120 mm なら +20）。Secondary 画像は省略でき、Primary 1 枚だけでも校正できます。
4. **ピークリスト (Peak List)** で、両方の画像に現れるピークの d 値を選びます（通常は各画像で 3 本以上。2 枚使う場合は、少なくとも 1 本を両方の画像に共通させます。カメラ長だけを最適化する場合を除き、3 本未満では **実行! (Refine!)** は実行されません）。
5. 最適化するパラメータ（**波長 (Wave Length)**・**カメラ長 (Camera Length)**・**傾き補正 (Tilt Correction)**・**ピクセルサイズ (Pixel Size)**・**ピクセル歪み (Pixel Distortion)**・**中心位置 (Center Position)**・**球面補正 (Spherical Correction)**）を選びます。
6. **実行! (Refine!)** を実行します。［繰り返し］で指定した回数（既定 12 回）で自動的に止まります。結果を確かめたら **校正パラメータをメインフォームに送信 (Refined parameters => Main form)** で、メインフォームへ反映します。

!!! note
    2 枚の画像（ダブルカセット）を使うと、カメラ長と波長を分離して決めやすくなります。

## パラメータ決定：力ずく最適化（標準試料）

幾何学的最適化が収束しにくい場合は、[パラメータ校正（力ずく）](3-tools.md)でカメラ長・中心位置・傾き（必要なら波長）を総当たり探索します。スクリーンショット付きの詳しい手順は[パラメータ校正（力ずく）](6-find-parameter.md)を参照してください。

1. メインフォームに標準試料の画像を 1 枚読み込み、パラメータ校正（力ずく）を開いて、対応する標準物質を選びます。
2. メインフォームで中心位置をおおよそ合わせます（**中心位置 (Find Center)** が役立ちます）。
3. 最適化する項目を選び、現在値を中心とした刻み幅 **初期ステップ (Initial step)** と、片側に何ステップ探すか（**探索範囲 (Search range)**）を指定します。平面検出器では画素サイズは探索の対象になりません。数値の例は[パラメータ校正（力ずく）](6-find-parameter.md)を参照してください。
4. **画像範囲の設定 (Integral Region)** はスリット（**矩形 (Rectangle)**）モードで帯幅を狭くするとノイズを抑えられます。
5. **最適化 (Optimize)** で探索を始めます。各サイクルで評価値 R が最小になった組み合わせが採用され、メインフォームのパラメータに自動で反映されます。

## 自動処理（Auto Procedure）

実験中などに、フォルダへ届く画像を自動で処理します。詳細は[各種ツール](3-tools.md)を参照してください。

1. **設定 (Set)** で監視フォルダを選びます。
2. 必要なら **パターンマッチング (Pattern matching)**（ファイル名末尾の番号）や **キーワード (Keyword)** でファイルを絞り込みます。
3. **新しい画像が読み込まれたら 以下の一連の操作を実行 (Once the new image is loaded, perform the following sequence)** を有効にし、リストから **自動コントラスト (Auto contrast)** / **中心位置検索 (Find center)** / **スポット検出 (Mask spots)** / **一次元化 (Get profile)** / **マクロ実行 (Execute macro)** を選びます。
4. 最後に **新しい画像を自動で読み込む (Automatically load new images)** をオンにして監視を始めます（フォルダが未指定だとオンにできません。番号・キーワードの条件は監視を始めた時点のものが使われます）。条件に合う画像が届くたびに一連の処理が自動実行されます。書き込み待ち（約 50 秒）の後もロックされていたファイルは、後の走査で再び試し、最初に見つけてから 10 分たっても読めなければ諦めます。

## マクロを用いた手順（Python ベース）

繰り返しや条件分岐を含む処理は、[マクロ](5-macro/index.md)で記述できます。マクロエディタの **サンプルを表示 (Show samples)** で見られるサンプルマクロが出発点になります。

- 画像を読み込み、線源・検出器（中心・カメラ長・画素）を設定して表示を合わせる
- 同心円積分の条件（開始・終了・ステップ・単位）を設定して一次元化し、CSV 保存する
- 複数ファイルを一括処理し、各画像の隣に CSV を保存する
- マルチフレーム画像をフレームごとに処理する
- デバイ環を N 個の扇形に分割して方位角依存を解析する
- マスク（全消去 → スポットマスク → ビームストップ部のマスク → マスク保存）して一次元化する
- 円周方向（cake）積分で方位角 vs 強度を出力する
- クリップボード送信を有効にして一次元化し、PDIndexer の名前付きマクロ（例: ピークフィット）を呼ぶ

ユーザーが書いたマクロは保存して名前で呼び出せ、Auto Procedure からも実行できます。
