# Q&A (자주 묻는 질문)

이 페이지에는 자주 받는 질문과 오해하기 쉬운 점을 모았습니다. 라벨은 한국어 UI 의 표시명이며, 괄호 안은 영어 UI 의 이름입니다. 여기서 다루지 않는 질문이나 버그 보고는 [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues) 를 이용해 주십시오.

## 설치와 시작

### 속성 창만 나타나고 메인 창이 보이지 않는다

메인 창이 화면 밖에 놓여 있습니다.

1. 작업 표시줄의 IPAnalyzer 아이콘 위에 마우스를 올리고, 미리 보기 썸네일을 오른쪽 클릭하여 **이동 (Move)** 을 선택한 뒤, 화살표 키를 한 번 누르고 마우스를 움직입니다.
2. 그래도 안 되면 IPAnalyzer 를 종료하고, 레지스트리 편집기 (regedit) 를 열어 `HKEY_CURRENT_USER\Software\Crystallography\IPAnalyzer` 를 삭제한 뒤 IPAnalyzer 를 다시 시작합니다 (모든 설정이 기본값으로 돌아갑니다).

### 업데이트했는데 이전 버전이 실행된다 / IPAnalyzer 가 더 이상 시작되지 않는다

[최신 릴리스](https://github.com/seto77/IPAnalyzer/releases/latest)에서 직접 다시 설치하십시오. 설치해도 이전 버전이 덮어써지지 않거나 프로그램이 시작되지 않으면, Windows 설정에서 한 번 제거한 다음 다시 설치하십시오. 새 버전에 문제가 있으면 같은 릴리스 페이지에서 이전 버전을 설치할 수 있습니다.

### 관리자 권한이 없는 PC 나 Windows on Arm 에서 사용하고 싶다

- 관리자 권한이 없으면, 설치가 필요 없고 .NET 런타임이 포함된 포터블 버전 (`IPAnalyzer-v.<version>.zip`) 을 사용하십시오.
- Windows on Arm 에서는 arm64 설치 프로그램 (`IPAnalyzer-setup_arm64.msi`) 이나 포터블 버전 (`IPAnalyzer-v.<version>_arm64.zip`) 을 사용하십시오.

자세한 내용은 [개요의 설치](0-overview.md#설치)를 참조하십시오.

### 많은 프레임을 불러오면 오류가 난다. 메모리는 얼마나 필요한가?

IPAnalyzer 는 원래의 비트 깊이와 관계없이 모든 픽셀의 강도를 배정밀도 (8바이트) 로 보관합니다. 예를 들어 1554×516 픽셀 이미지 5000장은 강도만으로 약 32 GB 가 필요합니다. 프레임이 많은 데이터는 메모리가 충분한 PC 에서 다루거나, 매크로로 나누어 처리하십시오.

## 이미지 읽기

### 내 검출기의 파일을 읽을 수 없다

아직 지원하지 않는 포맷일 수 있습니다. [Issues](https://github.com/seto77/IPAnalyzer/issues) 나 작성자에게 실제 파일 (어두운 이미지만이 아니라, 가능하면 회절 패턴이 찍힌 것) 과 함께 연락해 주십시오. 강도의 정확성과 이미지의 방향은 패턴이 보이는 이미지로만 확인할 수 있습니다.

!!! note "raw 이미지의 폭과 높이가 잘못된 경우"
    헤더가 없는 raw 파일은 파일 크기로부터 검출기 모델과 픽셀 수를 추정합니다. 실제 픽셀 수가 카탈로그 값과 다른 경우가 많으므로, 판정에 실패하면 파일을 보내 주십시오.

### 매개변수 파일을 불러온 뒤 이미지를 열면 매개변수가 바뀐다

IPAnalyzer 는 **카메라 길이, 파장, 픽셀 크기 같은 매개변수를 이미지 포맷마다 기억**하며, 이미지를 열면 그 값으로 전환합니다. 따라서 매개변수 파일 (`.prm`) 은 **이미지를 연 뒤에** 불러오십시오. 확장자가 다른 포맷은 내용이 같더라도 따로 기억됩니다.

### 이미지마다 뒤집기나 회전을 다시 해야 하는가?

아닙니다. **옵션 (Option) → 뒤집기 (Flip) / 회전 (Rotate)** 설정도 이미지 포맷마다 기억되어, 다음에 같은 포맷의 이미지를 열 때 자동으로 적용됩니다. 뒤집기와 회전은 적분과 이미지 저장에도 영향을 줍니다 (원본 파일은 바뀌지 않습니다).

### 여러 프레임이 들어 있는 파일 (`.his`, `.nxs`, 다중 페이지 TIFF, …) 은 어떻게 다루는가?

그런 파일을 불러오면 **연속 이미지 (Sequential image)** 창이 열리고, 표시할 프레임을 선택할 수 있습니다. 한꺼번에 적분하려면 **프로파일 가져오기 (Get Profile)** 드롭다운의 **모든 연속 이미지 프로파일 가져오기 (Get Profiles for all sequential images)** 또는 **선택한 이미지 프로파일 가져오기 (Get Profiles for selected images)** 를 사용합니다. 자세한 내용은 [도구](3-tools.md#연속-이미지-sequential-image)를 참조하십시오.

## 보정

### 매개변수 찾기 (기하학적) 와 매개변수 찾기 (전수 탐색) 는 어떻게 구분해서 쓰는가?

| | 기하학적 (geometrically) | 전수 탐색 (brute force) |
|---|---|---|
| 원리 | 이미지를 섹터로 나누어 피크 위치를 구하고, Debye 고리의 타원 모양과 중심으로부터 중심, 기울기 등을 결정 | 매개변수를 단계적으로 바꾸어, 계산한 피크 위치와 피팅한 피크 위치가 가장 잘 맞는 조합을 탐색 |
| 적합한 데이터 | 고리가 거의 한 바퀴 전체에 걸쳐 보이는 경우 (적어도 다섯 방향) | 고리의 일부만 기록된 경우, 다이렉트 스폿이 이미지 밖에 있는 경우, 스폿이 많은 고리 |
| 이미지 | 한 장, 또는 카메라 길이를 바꾸어 찍은 두 장 | 한 장 |
| 주의 | 고리가 한 바퀴 전체에 걸쳐 보이지 않으면 정확도가 떨어지거나 정밀화가 수렴하지 않음 | 상당히 좋은 초기값이 필요하며, 시간이 걸림 |

절차는 [작업 절차](4-procedures.md)와 [매개변수 찾기 (전수 탐색)](6-find-parameter.md)를 참조하십시오.

### 보정에는 어떤 표준 시료를 써야 하는가?

미세한 입자로부터 매끄러운 (스폿이 많지 않은) Debye 고리를 주고, 가능한 한 한 바퀴 전체가 보이는 시료가 적합합니다. 고리가 다섯 개 이상 있는 것이 기준입니다. 완전한 고리가 두 개뿐이면 정밀한 결정이 어려우며, 파장이나 카메라 길이 중 하나는 알고 있어야 합니다. 전수 탐색 보정에서는 표준 물질을 Au / CeO₂ / LaB₆ / Al₂O₃ 중에서 고르거나, **기타 (Other)** 를 선택하여 격자 상수를 입력합니다.

### 보정이 수렴하지 않는다 / 중심이 계속 어긋난다

- 믿을 수 있는 값 (카탈로그 픽셀 크기, 알고 있는 파장 등) 은 고정하고, 정밀화하는 변수의 수를 줄이십시오.
- 먼저 저각 고리 몇 개로 대략 맞춘 다음, 고각 고리를 추가하십시오.
- 해석에 실패한 고리 하나가 전체 결과를 흐트러뜨릴 수 있습니다. 고리 중심 그래프에서 하나만 동떨어진 고리가 있으면 제거하십시오.
- 고각 고리를 포함하면 피팅이 실패하는 경우, 고리가 아직 한 바퀴 전체에 걸쳐 보이는 피크로 제한하고, 피팅 범위를 넓히고, 섹터 수를 줄이십시오.
- 시작하기 전에 가능한 한 정확한 초기값을 입력하십시오.

### 카메라 길이와 파장은 한쪽을 고정해야만 결정할 수 있는가?

격자 상수를 정확히 아는 표준 물질이라면, 이미지 한 장으로도 (고리 위치의 비로부터) 둘 다 결정할 수 있습니다. 다만 **카메라 길이와 픽셀 크기는 이미지 한 장으로 동시에 결정할 수 없습니다**. 카탈로그 픽셀 크기를 믿고 고정하십시오. 카메라 길이 차이를 알고 있는 두 장의 이미지 (double-cassette 법) 가 있으면 픽셀 크기도 정밀화할 수 있습니다.

### 다이렉트 스폿이 기록되지 않았다 / 이미지 밖에 있다

다이렉트 스폿 위치를 직접 입력하고, **프로파일 가져오기 (Get Profile)** 드롭다운의 **프로파일 가져오기 전 중심 찾기 (Find Center before Get Profile)** 를 해제하십시오. 스폿이 이미지 밖에 있으면 음의 좌표도 괜찮습니다. 이런 데이터에는 전수 탐색 보정을 사용하십시오.

### 중심 찾기로 구한 중심이 보정으로 구한 중심과 몇 픽셀 다르다

결정하는 방법이 다르기 때문입니다. **중심 찾기 (Find Center)** 는 현재 중심 근처의 다이렉트 스폿을 2차원 pseudo-Voigt 함수로 피팅합니다. 보정은 다이렉트 스폿의 강도를 사용하지 않고, 여러 Debye 고리의 타원 중심으로부터 중심을 구합니다. 기울기가 올바르게 결정되었다면 보정으로 구한 중심을 그대로 사용해도 됩니다. 다이렉트 스폿이 포화된 경우에는 **링 그리기 (Draw ring)** 로 Debye 고리 위에 원을 표시한 다음 **중심 찾기 (Find Center)** 를 누르십시오. 그러면 고리로부터 중심이 결정됩니다.

### 구면 보정이란 무엇인가?

구면처럼 휘어진 검출기를 위한 보정입니다. 곡률 반지름의 역수 1/R (mm⁻¹) 을 입력합니다. 평판 검출기에서는 0 으로 합니다. 큰 검출기를 시료 가까이에 둔 경우처럼 고각 고리가 맞지 않을 때 도움이 됩니다.

### 다른 소프트웨어 (PIP 등) 의 기울기 값은 어떻게 변환하는가?

PIP 의 (β, Φ) 는 IPAnalyzer 의 (φ, τ) = (270° − β, Φ) 로 변환됩니다. 정의는 [개요](0-overview.md#winpip와의-관계)를 참조하십시오.

## 적분과 출력

### 결과의 가로축이 이상하다 / 강도가 거의 일정해 보인다

속성 창의 **적분 속성 (Integral Property)** 탭에서 **방사 적분 (Radial integration)** 이 선택되어 있지 않은지 확인하십시오. 이 모드에서는 프로파일의 가로축이 방위각 χ 가 됩니다. 일반적인 2θ–강도 프로파일은 **동심 적분 (Concentric integration)** 으로 얻습니다.

### PDIndexer 없이 프로파일을 파일로 저장하고 싶다

속성 창의 **"프로파일 가져오기" 후 (After "Get Profile")** 탭에서, **Save File** 아래의 저장 위치 (이미지와 같은 폴더 / 매번 선택) 와 형식 (PDI / CSV / TSV / GSAS) 을 설정하십시오. 그러면 적분할 때마다 프로파일이 저장됩니다.

### CSV 의 세 번째 열은 무엇인가?

강도의 계수 오차입니다. 각 스텝에서 합산된 픽셀 강도를 계수로 보고, 그 제곱근으로 계산합니다. 두 번째 열의 강도는 Bragg–Brentano 기하에 상당하는 값으로 변환되어 있으므로, 세 번째 열의 제곱과 같지 않습니다. PDIndexer 에서는 이를 오차 막대로 표시할 수 있습니다.

### CSV 의 2θ 값이 소수 둘째 자리까지밖에 없다. 그것이 정밀도의 한계인가?

아닙니다. 예를 들어 시작 20.00°, 스텝 0.01° 로 적분을 설정했기 때문에 그렇게 보일 뿐입니다. 계산은 배정밀도로 수행됩니다. 결과의 정밀도는 카메라 길이나 파장 같은 입력 매개변수의 오차로 결정됩니다.

### 연속 이미지에서는 평균과 합산 중 어느 쪽을 써야 하는가?

S/N 비는 어느 쪽이든 같습니다. **합산 (Summation)** 은 오차를 올바르게 추정하므로, Rietveld 정밀화처럼 오차를 사용하는 해석에는 합산을 권장합니다.

### 방위각마다 (섹터마다) 적분하고 싶다

**프로파일 가져오기 (Get Profile)** 드롭다운의 **방위각 분할 분석 (Azimuthal Division Analysis)** 을 켜고, **분할 개수 (Number of divisions)** 를 설정한 뒤 적분하십시오. 전체 프로파일 (이름이 `-whole` 로 끝남) 과 섹터마다의 프로파일 (`-000`, `-010`, … 처럼 시작 각도가 덧붙음) 이 만들어집니다. 분할 수가 너무 많으면 PDIndexer 로 보내는 데이터가 너무 커질 수 있습니다.

### 2θ 와 방위각 χ 의 2차원 맵 (펼친 이미지) 을 원한다

도구 모음의 **이미지 펼치기 (Unroll image)** 를 사용하십시오. 범위와 스텝은 속성 창의 **펼친 이미지 옵션 (Unrolled Image Option)** 탭에서 설정합니다. **파일 (File) → 이미지 저장 (Save image)** 에서 TIFF 는 계산된 부동소수점 값을 유지하고, PNG 는 화면에 보이는 그대로 저장합니다.

### 이미지의 직사각형 부분에 대한 강도의 합이나 평균을 알고 싶다

이미지 위에서 Ctrl + 오른쪽 드래그로 직사각형을 선택하십시오. 아래쪽의 **통계 정보 (Statistical Information)** 탭에 통계가 표시됩니다. 연속 이미지에서는 같은 영역을 프레임 사이에서 비교할 수 있습니다.

### 어두운 이미지인데 고각 쪽 가장자리로 갈수록 밝아진다

속성 창의 **파원 (Wave source)** 에서 **선편광 보정 (Correct linear polarization)** 이 켜져 있으면, X선에서 오지 않은 신호 (암전류, 전자 잡음) 에도 보정이 적용되어 고각 쪽이 밝아집니다. 어두운 이미지에서는 끄십시오.

### 다크 (배경) 이미지를 빼고 싶다

속성 창의 **배경 옵션 (Background Option)** 탭에서 현재 이미지를 배경으로 등록하고 계수를 설정하십시오. 그 후에는 같은 크기의 이미지에서 자동으로 빼집니다. 자세한 내용은 [속성 창](2-property-windows.md)을 참조하십시오.

## 일괄 처리와 매크로

### 많은 파일을 한 번에 적분하고 싶다

**모든 연속 이미지 프로파일 가져오기 (Get Profiles for all sequential images)** 는 한 파일에 들어 있는 여러 프레임용입니다. 여러 파일을 처리하려면 [매크로](5-macro/index.md)를 사용하십시오. [예제](5-macro/2-examples.md)에는 선택한 파일들을 차례로 적분하여 CSV 파일로 저장하는 예가 있습니다. 실행하기 전에 이미지 하나를 열고 매개변수 파일을 불러오십시오 ([매개변수 기억](#매개변수-파일을-불러온-뒤-이미지를-열면-매개변수가-바뀐다) 참조).

### 자주 쓰는 매크로를 메뉴에서 호출하고 싶다

매크로 편집기에서 매크로에 이름을 붙여 추가하면, 메인 창의 **매크로 (Macro)** 메뉴에서 호출할 수 있습니다.

### 측정 중에 도착하는 이미지를 바로 적분하고 싶다

[자동 절차 (Auto procedure)](3-tools.md#자동-절차-auto-procedure)로 폴더를 감시하십시오. 아직 쓰는 중인 파일은 쓰기가 끝난 뒤에 읽힙니다. 네트워크상의 폴더에서 읽기에 실패하면, 측정 PC 의 로컬 디스크에 저장하고 그 폴더를 감시하십시오.

## 버그 보고

### 버그를 보고할 때 무엇을 보내야 하는가?

작성자의 환경에서는 문제가 재현되지 않는 경우가 많으므로, 다음을 첨부해 주십시오.

- 그때의 매개변수 파일 (**파일 (File) → 매개변수 저장 (Save parameter)**),
- 문제가 발생한 이미지 파일,
- 오류 메시지 (스크린샷도 괜찮습니다) 와 IPAnalyzer 버전.

[GitHub Issues](https://github.com/seto77/IPAnalyzer/issues) 를 통해 보고해 주십시오.

## 흔한 오해

| 생각 | 실제 |
|---|---|
| 매개변수 파일을 먼저 불러오고 나서 이미지를 연다 | 이미지를 열면 그 포맷에 대해 기억된 값으로 전환됩니다. 이미지를 먼저 열고 나서 매개변수 파일을 불러오십시오 |
| **모든 연속 이미지 프로파일 가져오기 (Get Profiles for all sequential images)** 는 여러 파일을 한 번에 처리한다 | 한 파일 안의 여러 프레임용입니다. 여러 파일에는 매크로를 사용하십시오 |
| 프로파일을 저장하려면 PDIndexer 가 필요하다 | IPAnalyzer 만으로 파일에 저장할 수 있습니다 ("프로파일 가져오기" 후 (After "Get Profile") 탭) |
| CSV 의 세 번째 열은 또 다른 프로파일이다 | 강도의 계수 오차입니다 |
| 합산하면 S/N 이 좋아진다 | S/N 은 평균과 같으며, 오차 추정만 다릅니다 |
| 카메라 길이와 픽셀 크기를 이미지 한 장으로 둘 다 결정할 수 있다 | 한 장으로는 동시에 결정할 수 없습니다. 픽셀 크기는 카탈로그 값으로 고정하십시오 |
| 뒤집기와 회전은 표시만 바꾼다 | 적분과 이미지 저장에도 영향을 줍니다 |
| PDIndexer 로 보내면 프로파일에 로렌츠-편광 보정이 적용된다 | PDIndexer 는 계산된 회절선의 강도에 대해서만 편광을 고려하며, 프로파일 자체는 수정되지 않습니다 |
