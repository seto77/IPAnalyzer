# 매크로

IPAnalyzer 는 Python 과 비슷한 스크립트로 일련의 조작을 자동화하는 **매크로** 기능을 제공합니다. 많은 파일의 일괄 1차원화, 포맷 변환, 방위각 분할 해석 같은 반복 작업에 유용합니다.

## 편집기 열기

메인 창의 **매크로 (Macro)** 메뉴 → **편집기 (Editor)** 에서 매크로 편집기를 엽니다. 편집기에서 코드를 편집하고, 단계 실행을 포함하여 실행할 수 있습니다.

![매크로 편집기](../../assets/cap-en-auto/FormMacro.png)

## 언어

- `for` / `if` / `while` / `def` / `class` 같은 제어문과 산술 연산을 사용할 수 있습니다.
- `math` 모듈이 미리 임포트되어 있으므로, `import` 문 없이 `math.pi` 나 `math.sin(...)` 을 바로 사용할 수 있습니다.
- `print()` 는 사용할 수 없습니다. 값을 확인하려면 **단계 실행** (Step by step) 을 사용하여 디버그 패널에서 변수의 변화를 지켜보십시오.
- IPAnalyzer 의 각 조작은 `IPA` 루트 객체 아래의 네임스페이스 (예: `IPA.File`) 에서 호출합니다.

## IPA 네임스페이스

| 네임스페이스 | 역할 |
|------|------|
| `IPA.File` | 이미지, 매개변수, 마스크 파일의 읽기/쓰기; 파일 선택 대화 상자 |
| `IPA.Wave` | 입사 선원과 파장 설정 |
| `IPA.Detector` | 검출기 기하 설정: 중심, 카메라 길이, 픽셀 크기, 기울기 |
| `IPA.Image` | 표시 스케일, 대비, 표시 영역 제어 |
| `IPA.Mask` | 스폿과 영역의 마스크 |
| `IPA.Profile` | 1차원화 (Get Profile) 실행과 저장/전송 설정 |
| `IPA.IntegralProperty` | 동심 / 방사 적분의 범위, 스텝, 단위 설정 |
| `IPA.Sequential` | 다중 프레임 이미지의 프레임 선택 / 평균 / 대상 지정 |
| `IPA.PDI` | PDIndexer 의 매크로 호출 (클립보드 연동) |

멤버 목록은 [내장 함수](1-built-in-functions.md)를, 구체적인 스크립트는 [예제](2-examples.md)를 참조하십시오.

!!! tip "편집기 내 도움말이 정본입니다"
    각 함수/속성의 설명은 매크로 편집기의 도움말에 표시되며, 이것이 버전을 따라가는 최신 정본입니다. 이 페이지와 편집기 내 도움말이 다르면 후자를 믿으십시오.

## 예제 매크로

편집기에서 **예제 표시 (Show samples)** 를 켜면 읽기 전용 예제 매크로 (기본 루프, 수학 함수, 기하 설정, 일괄 처리, 방위각 분할, 마스킹, PDIndexer 로 전송 등) 가 나열되고, 끄면 직접 저장한 매크로로 돌아갑니다. 고쳐 쓰기 쉬운 출발점입니다.

## 자동 절차와 함께 사용하기

작성한 매크로는 이름을 붙여 저장할 수 있고, [자동 절차 (Auto Procedure)](../3-tools.md)의 "불러온 후 실행" 목록에서도 호출할 수 있습니다. 이렇게 하면 실험 중에 도착하는 각 이미지에 매크로가 자동으로 적용됩니다.
