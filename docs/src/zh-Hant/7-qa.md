# Q&A（常見問題）

本頁彙整最常被詢問的問題，以及容易誤解的要點。文中的標籤為繁體中文介面中的顯示名稱，括號內為英文名稱。若有本頁未涵蓋的問題，或要回報錯誤，請使用 [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues)。

## 安裝與啟動

### 只出現屬性視窗，看不到主視窗

主視窗被放到畫面之外了。

1. 將滑鼠移到工作列上的 IPAnalyzer 圖示，在縮圖上按右鍵，選擇 **移動 (Move)**，按一次方向鍵，然後移動滑鼠。
2. 若仍無效，請結束 IPAnalyzer，開啟登錄編輯程式 (regedit)，刪除 `HKEY_CURRENT_USER\Software\Crystallography\IPAnalyzer`，再重新啟動 IPAnalyzer（所有設定都會回到預設值）。

### 更新後仍在執行舊版本／IPAnalyzer 無法啟動

請直接從[最新版本](https://github.com/seto77/IPAnalyzer/releases/latest)重新安裝。若安裝時沒有覆蓋舊版本，或程式無法啟動，請先從 Windows 設定中解除安裝，再重新安裝。若新版本有問題，也可以從同一個 releases 頁面安裝舊版本。

### 想在沒有系統管理員權限的電腦或 Windows on Arm 上使用

- 沒有系統管理員權限時，請使用可攜版（`IPAnalyzer-v.<version>.zip`），它免安裝且內含 .NET 執行階段。
- 在 Windows on Arm 上，請使用 arm64 安裝程式（`IPAnalyzer-setup_arm64.msi`）或可攜版（`IPAnalyzer-v.<version>_arm64.zip`）。

詳細內容請參見[概觀中的「安裝」](0-overview.md#安裝)。

### 載入大量影格時發生錯誤。需要多少記憶體？

無論原始的位元深度為何，IPAnalyzer 都會以雙精度（8 位元組）保存每個像素的強度。例如，5000 張 1554×516 像素的影像，光是強度就需要約 32 GB。影格數多的資料請在記憶體充足的電腦上處理，或以巨集分批處理。

## 讀取影像

### 無法讀取我的偵測器的檔案

可能尚未支援該格式。請透過 [Issues](https://github.com/seto77/IPAnalyzer/issues) 或直接與作者聯繫，並附上實際的檔案（最好是有繞射圖樣的影像，而不只是暗影像）。強度是否正確以及影像的方向，只能以顯示出圖樣的影像來確認。

!!! note "raw 影像的寬度與高度錯誤時"
    對於沒有標頭的 raw 檔案，會依檔案大小推斷偵測器型號與像素數。實際的像素數常與型錄值不同，因此若偵測失敗，請將檔案寄給我們。

### 載入參數檔後再開啟影像，參數就改變了

IPAnalyzer **會依影像格式記住相機長度、波長、像素尺寸等參數**，並在開啟影像時切換為這些值。因此請 **在開啟影像之後** 再載入參數檔（`.prm`）。副檔名不同的格式，即使內容相同也會分別記憶。

### 每張影像都要重新翻轉或旋轉嗎？

不需要。**選項 (Option) → 翻轉 / 旋轉 (Flip / Rotate)** 的設定也會依影像格式記憶，下次開啟相同格式的影像時會自動套用。翻轉與旋轉也會影響積分與影像儲存（原始檔案不會變更）。

### 含多個影格的檔案（`.his`、`.nxs`、多頁 TIFF 等）如何處理？

載入這類檔案時，會開啟 **連續影像 (Sequential image)** 視窗，可選擇要顯示的影格。若要一併積分，請使用 **取得圖譜 (Get Profile)** 下拉選單中的 **取得所有連續影像的圖譜 (Get Profiles for all sequential images)** 或 **取得選取影像的圖譜 (Get Profiles for selected images)**。詳細內容請參見[工具](3-tools.md#連續影像-sequential-image)。

## 校正

### 何時使用「尋找參數 (幾何法)」，何時使用「尋找參數 (暴力法)」？

| | 尋找參數 (幾何法) (Find parameter (geometrically)) | 尋找參數 (暴力法) (Find parameter (brute force)) |
|---|---|---|
| 原理 | 將影像分割為扇形並求出峰位置，再由 Debye 環的橢圓形狀與中心決定中心、傾斜等 | 逐步改變參數，尋找計算的峰位置與擬合所得的峰位置最吻合的組合 |
| 適用資料 | 圓環幾乎一整圈都看得到（至少五個方向） | 只記錄到部分圓環、直射點在影像外、斑點狀的圓環 |
| 影像 | 一張，或在不同相機長度下拍攝的兩張 | 一張 |
| 注意 | 若圓環無法看到一整圈，精度會下降或精修無法收斂 | 需要相當好的初始值；耗時 |

步驟請參見[操作步驟](4-procedures.md)與[尋找參數（暴力搜尋）](6-find-parameter.md)。

### 校正應使用哪種標準試料？

適合使用由細小晶粒產生平滑（非斑點狀）Debye 環、且圓環盡可能完整可見的試料。以約五個以上的圓環為參考標準。若只有兩個完整的圓環，就難以精確決定，此時波長或相機長度其中之一應為已知。暴力法校正時，標準物質可從 Au / CeO₂ / LaB₆ / Al₂O₃ 中選擇，或選擇 **其他 (Other)** 並輸入晶格常數。

### 校正無法收斂／中心不斷漂移

- 固定可信任的值（型錄上的像素尺寸、已知的波長等），減少精修的變數數目。
- 先以少數幾個低角度的圓環粗略擬合，再加入高角度的圓環。
- 解析失敗的圓環可能會擾亂整體結果。若在環中心圖表中有某個圓環明顯偏離，請將其移除。
- 若加入高角度圓環後擬合失敗，請將峰限制為圓環仍可看到一整圈者、加大擬合範圍，並減少扇形的數目。
- 開始前請輸入盡可能正確的初始值。

### 相機長度與波長是否只有在固定其中之一時才能決定？

使用晶格常數已精確得知的標準物質時，即使只有一張影像，也能（由各圓環位置的比值）同時決定兩者。但 **無法僅從一張影像同時決定相機長度與像素尺寸**。請信任型錄上的像素尺寸並將其固定。若使用兩張已知相機長度差的影像（雙卡匣法），也能精修像素尺寸。

### 直射點沒有被記錄到／位於影像之外

請手動輸入直射點位置，並取消 **取得圖譜 (Get Profile)** 下拉選單中的 **取得圖譜前先尋找中心 (Find Center before Get Profile)**。若直射點位於影像之外，輸入負的座標也沒有問題。這類資料請使用暴力法校正。

### 「尋找中心」求得的中心與校正後的中心相差數個像素

兩者的決定方式不同。**尋找中心 (Find Center)** 會以二維 pseudo-Voigt 函數擬合目前中心附近的直射點。校正則不使用直射點的強度，而是從多個 Debye 環的橢圓中心推導出中心。只要傾斜已正確決定，校正後的中心即可直接使用。若直射點已飽和，請以 **繪製環 (Draw ring)** 在某個 Debye 環上顯示圓，再按下 **尋找中心**：此時中心會依據該圓環決定。

### 什麼是球面校正？

這是針對彎曲成球面狀之偵測器的校正。請輸入曲率半徑的倒數 1/R (mm⁻¹)。平面偵測器請設為 0。當高角度的圓環對不上時（例如將大型偵測器放在靠近試料的位置），此校正會有幫助。

### 如何換算其他軟體（如 PIP）的傾斜值？

PIP 的 (β, Φ) 換算為 IPAnalyzer 的 (φ, τ) = (270° − β, Φ)。定義請參見[概觀](0-overview.md#與-winpip-的關係)。

## 積分與輸出

### 結果的橫軸看起來不對／強度看起來幾乎是定值

請確認屬性視窗的 **積分性質 (Integral Property)** 分頁中是否選擇了 **徑向積分 (Radial integration)**。此模式下曲線的橫軸為方位角 χ。一般的 2θ–強度曲線請以 **同心積分 (Concentric integration)** 取得。

### 不使用 PDIndexer，想將曲線儲存為檔案

在屬性視窗的 **「取得圖譜」之後 (After "Get Profile")** 分頁中，於 **Save File** 下設定儲存位置（與影像相同的資料夾／每次選擇）與格式（PDI / CSV / TSV / GSAS）。之後每次積分時都會儲存曲線。

### CSV 的第三欄是什麼？

這是強度的計數誤差，將每個步進中加總的像素強度視為計數，由其平方根計算而得。第二欄的強度已換算為相當於 Bragg–Brentano 幾何的值，因此不會等於第三欄的平方。PDIndexer 可將其顯示為誤差棒。

### CSV 中的 2θ 值只有小數點後兩位。這是精度的極限嗎？

不是。這只是因為積分設定為例如起始 20.00°、步進 0.01°，所以看起來如此。計算是以雙精度進行。結果的精度由相機長度、波長等輸入參數的誤差決定。

### 對於連續影像，應使用「平均」還是「加總」？

兩者的 S/N 比相同。**加總 (Summation)** 能正確估計誤差，因此建議用於 Rietveld 精修等會使用誤差的分析。

### 想依各方位角（各扇形）進行積分

開啟 **取得圖譜 (Get Profile)** 下拉選單中的 **方位角分割分析 (Azimuthal Division Analysis)**，設定 **分割數 (Number of divisions)** 後進行積分。會產生一條整體曲線（名稱以 `-whole` 結尾），以及每個扇形各一條曲線（附加起始角度，如 `-000`、`-010`、…）。分割數過多時，傳送至 PDIndexer 的資料可能會過大。

### 想取得 2θ 與方位角 χ 的二維對應圖（展開影像）

請使用工具列上的 **展開影像 (Unroll image)**。範圍與步進在屬性視窗的 **展開影像選項 (Unrolled Image Option)** 分頁中設定。使用 **檔案 (File) → 儲存影像 (Save image)** 時，TIFF 會保留計算出的浮點數值，PNG 則儲存畫面上顯示的內容。

### 想取得影像中某個矩形區域的強度總和或平均

在影像上以 Ctrl + 右鍵拖曳選取矩形。統計量會顯示在下方的 **統計資訊 (Statistical Information)** 分頁中。對於連續影像，也可以跨影格比較相同區域。

### 暗影像越靠近高角度的邊緣越亮

若屬性視窗的 **波源 (Wave source)** 中開啟了 **校正線偏振 (Correct linear polarization)**，校正也會套用到非來自 X 射線的訊號（暗電流、電子雜訊），使高角度側變亮。處理暗影像時請將其關閉。

### 想扣除暗（背景）影像

在屬性視窗的 **背景選項 (Background Option)** 分頁中，將目前影像登錄為背景並設定係數。之後會自動從相同尺寸的影像中扣除。詳細內容請參見[屬性視窗](2-property-windows.md)。

## 批次處理與巨集

### 想一次積分大量檔案

**取得所有連續影像的圖譜 (Get Profiles for all sequential images)** 是針對單一檔案中所含的多個影格。若要處理多個檔案，請使用[巨集](5-macro/index.md)。[範例](5-macro/2-examples.md)中有依序積分所選檔案並儲存 CSV 檔的範例。執行前，請先開啟一張影像並載入參數檔（參見[參數的記憶](#載入參數檔後再開啟影像參數就改變了)）。

### 想從選單呼叫常用的巨集

在巨集編輯器中為巨集命名並加入後，即可從主視窗的 **巨集 (Macro)** 選單中呼叫。

### 想在量測期間於影像產生時即進行積分

請以[自動程序 (Auto procedure)](3-tools.md#自動程序-auto-procedure) 監看資料夾。仍在寫入中的檔案會在寫入完成後才讀取。若網路上的資料夾讀取失敗，請將資料儲存到量測電腦的本機磁碟，並監看該資料夾。

## 回報錯誤

### 回報錯誤時應附上什麼？

問題常常無法在作者的環境中重現，因此請附上：

- 當時的參數檔（**檔案 (File) → 儲存參數 (Save parameter)**）、
- 發生問題的影像檔，以及
- 錯誤訊息（螢幕截圖即可）與 IPAnalyzer 的版本。

請透過 [GitHub Issues](https://github.com/seto77/IPAnalyzer/issues) 回報。

## 常見的誤解

| 以為 | 實際上 |
|---|---|
| 先載入參數檔，再開啟影像 | 開啟影像時會切換為該格式所記憶的值。請先開啟影像，再載入參數檔 |
| **取得所有連續影像的圖譜** 可一次處理多個檔案 | 它是針對單一檔案中的多個影格。多個檔案請使用巨集 |
| 儲存曲線需要 PDIndexer | 僅用 IPAnalyzer 即可儲存為檔案（「取得圖譜」之後 (After "Get Profile") 分頁） |
| CSV 的第三欄是另一條曲線 | 它是強度的計數誤差 |
| 加總可改善 S/N | S/N 與平均相同；只有誤差的估計不同 |
| 從一張影像就能同時決定相機長度與像素尺寸 | 無法從一張影像同時決定；請將像素尺寸固定為型錄值 |
| 翻轉與旋轉只會改變顯示 | 它們也會影響積分與影像儲存 |
| 傳送至 PDIndexer 時會對曲線施加 Lorentz 偏振校正 | PDIndexer 只在計算繞射線的強度時考慮偏振；曲線本身不會被修改 |
